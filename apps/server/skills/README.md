# dob-skills

《二重螺旋》Agent 技能仓库。

技能以**普通目录**存放在这里，由 git 管理版本：新增 / 修改 / 删除技能都是普通提交，
服务端在清单与下载接口里**实时读取**（清单每次 stat 目录，无需重启；目录内容变更即生效）。
没有后台写入接口，也不需要上传 zip。

## 目录结构

```
skills/
└── <技能名>/
    ├── SKILL.md          # 入口文件，必须在技能目录根级
    └── references/       # 可选，按需加载的补充资料
```

## 约束

下发时服务端会按目录内容实时打包成 zip，校验口径见 `server/src/util/skill-source.ts`：

| 项 | 上限 |
|---|---|
| 技能名（目录名） | 小写 kebab-case（`^[a-z0-9][a-z0-9-]*$`），≤64 字符 |
| 描述 | 必填（写在 SKILL.md frontmatter），≤1024 字符 |
| 文件数 | ≤50 |
| 单文件 | ≤1MB |
| 全部文件合计 | ≤8MB |

根级**必须有 `SKILL.md`**。隐藏文件与 `__MACOSX` 会被忽略。

## SKILL.md 格式

```markdown
---
name: dna-jargon
description: 一段说明「这个技能干什么、什么时候用」，用中文，含触发关键词。
whenToUse: 可选，补充触发场景
version: 可选，信息性版本号
enabled: 可选，false 时不对客户端下发
sortOrder: 可选，数字，小者靠前
---

# 标题

正文……
```

**技能名以目录名为准**（`name` 字段仅供阅读）。`frontmatter` 只在服务端推导清单时使用，
注入模型前会被剥掉，所以元数据以服务端清单为准，不要在正文里重复描述。

> 这些技能是下发给**资料检索 Agent / 配装助手**阅读的文本。写技能时注意：
> ① 两个 Agent 工具面不同（**配装助手有 `run_code` 沙盒，资料检索 Agent 没有**）——
>    正文两者都会读到，别写「你没有 X」式的断言；只有一方做得到的指令要标明适用方。
> ② **不要复述 `read_entry` 能直接读到的原文**（术语定义 / 溯源原文 / 熔炼文案）——那是冗余，
>    还会与数据包产生第二份会过期的事实。技能该写**推导、换算、口径、字段落点**（数据包里没有结论的那一步）。
> ③ 技能里的事实必须回数据包核对过，别抄 `outputs/` 里的旧稿。
