# 步入梦乡 · 活动总览与攻略索引

> **本技能是什么**：「步入梦乡」（活动 id `102006`，站内资料页 `/db/transcendence`）是一套高复杂度的**暗黑式装备刷取、打造与冲层赛季玩法**。它包含「4 类委托 + 螺旋迷境（丰饶/荣耀）+ 梦魇迷境（6 首领）+ 5 阶段旅程与旅程增益 + 升华天赋 + 16 装备位与 7 工艺打造 + 宝石系统」一整套闭环。
>
> **时效与版本口径**：基于 **1.8** 本地数据包逐条核对（活动档期 `2026-11-01 ~ 2027-01-11`，推荐历练等级 **55 级**后体验）。活动结束后**升华装备、升华天赋、专属材料/镶嵌物/消耗品全部消失**，仅**旅程任务中的非活动专属奖励（月石、增幅激化器、熔炼模具）与排行头像框永久保留**。

## 先分清工具落点与适用方

- **资料检索 Agent**：`event`（id `102006`）仅含 4 行基础规则；`transcendence-talent` / `transcendence-affix` / `transcendence-unique` 三个模块目前**仅支持 `query_module_entries` / `search_data` 查摘要与路径，`read_entry` 对它们无详情字段**；`resource` 模块需传 `select: ["name","rarity","access","desc"]` 才能读来源与描述；`dungeon` 模块中 4 个委托的 `掉落` 字段不是升华 16 档奖励。**玩法机制、掉落曲线、打造公式、Boss 定向产出与天赋路线一律以本技能正文及 `references/` 为准**，需要站内链接时可用 `query_module_entries` 取 `path` 或直接引用本技能提供的 `/db/transcendence/...` 路径。
- **配装助手**：检索子集不含 `transcendence-*` / `event` / `resource` / `dungeon`，机制与攻略直接以本技能为准；若用户要量化「换某件升华装备 / 精锻 / 太古 / 暗金 / 天赋」对具体角色的 DPS 收益，可用 `run_code` 读写 `charSettings.transcend` 实算（资料检索 Agent 不跑代码，按本技能的乘区口径与公式定性分析，并指引用户前往 `/transcend-build/<charId>` 试算）。

## 核心玩法循环（一图读懂）

```
[4 类委托] ──刷基础经验 / 古币 / 精锻材料 / 过渡装备 + 三档钥匙
     │
     ▼
[螺旋迷境·丰饶] ──核心引擎：冲层解锁 16 档难度（30/45/60/80/100…136 层）
     │                 + 稳定产出 6 件装备 + 升级秘钥(一/二/三) + 宝石/碎片 + 流光之楔 + 钥匙
     ├─→ [升华天赋]（升华经验→天赋秘钥点亮节点；升级秘钥一/二/三升级高级节点至 Lv15/25/30）
     ├─→ [旅程任务 & 旅程增益]（完成关键任务解锁下阶段；旅程记录优先点满产出增益，反哺更多记录）
     ├─→ [材料兑换商店]（宝石碎片不限量换 1~5 级 6 色宝石；中期插满 3 级性价比最高）
     ├─→ [梦魇迷境 6 首领]（消耗普通/优质/豪华钥匙开箱：3/6/12 件装备 + 定向 6 枚蚀刻暗金戒 + 高概率精锻材料）
     └─→ [装备改造 7 工艺]（100 层解精锻/附魔，120 层解淬炼 → 打造强度 50 毕业装）
     │
     ▼
[螺旋迷境·荣耀] ──纯竞速冲层（限时 300s、无掉落），打旅程 110/120 层关键奖励 & 冲总榜/角色分组榜
```

## 开荒 → 毕业分阶段总路线

1. **起步期（难度 简单Ⅰ~普通Ⅱ，迷境 1~60 层）**：
   - 随便穿 4 件蓝装以上完成 **Phase 1 核心任务**（拿月石×300 + 100 万古币 + 解锁 Phase 2），**不要在强度 <50 的过渡装上投入附魔/精锻/打孔**（开孔/宝石仅随手完成旅程引导即可）。
   - **主推「丰饶的迷境」利用跳层快冲**（剩余时间 ≥300s 直接跳 10 层），每通 30 / 45 / 60 / 80 层立即手动切换大世界/副本**难度**（困难以上解锁钥匙、更高装备强度上限与品质掉率）。
   - 拿到**旅程记录**立刻花掉点**旅程增益**（前 4/8/12 份会触发 Phase 1/2/3 子任务各反哺 3 份），推荐优先点「**迷境古币**」与「**装备材料及流光之楔**」（缺等级点「升华经验」，最后补「宝石碎片」）。
2. **质变门槛①：丰饶迷境 100 层（解锁「挑战Ⅰ」）**：
   - 全活动**第一核心分水岭**：同时解锁 **装备强度上限 50（满档）**、**太古（升华词缀）掉落开关**、**精锻 / 最终精锻 / 附魔**功能、**升级秘钥·二**掉落、以及挑战Ⅰ起的全局掉落加成（经验 +40% / 古币 +30% / 材料与流光之楔 +20%）。
   - 此时**开始集中刷取强度 50 的金色（4 随机词缀）与暗金胚子**；用宝石碎片在材料兑换商店给主控 12 孔先插满 **3 级宝石**（仅 25 碎片/颗，拿到满级 60% 收益），并用存下来的钥匙去**挑战Ⅰ以上**开梦魇迷境宝箱刷对应属性的**蚀刻暗金戒**。
3. **质变门槛②：丰饶迷境 120 层（解锁「挑战Ⅵ」）**：
   - 全活动**第二核心分水岭**：解锁 **淬炼**（每件金色/暗金装多 1 条自选目标词缀！）与 **升级秘钥·三**掉落（把天赋高级节点冲到 Lv25 / Lv30 拿关键质变词条）。
   - 同步推进 **荣耀的迷境 110 / 120 层**拿下旅程 Phase 4/5 永久奖励（增幅激化器×1、熔炼模具×1）。
4. **终局毕业（难度 挑战Ⅵ~Ⅹ，迷境 120~136+ 层）**：
   - 通关任意迷境 **136 层**解锁最高难度 **挑战Ⅹ**（经验 +400% / 古币 +300% / 材料与流光之楔 +200%）。
   - 刷高保底/高概率层数丰饶迷境拿 `升级秘钥·三`、钥匙、4/5 级宝石与古币；委托按缺口切换（缺古币挂「扼守」，缺金属/水晶/精锻材料刷「避险」，缺胚子刷「驱离」，缺升华经验挂「探险」）；梦魇迷境定向追太古蚀刻戒与精锻水晶。
   - 按「**胚子筛选 → 附魔修 1 槽 → 淬炼补核心词缀 → 精锻 10 级 → 最终精锻洗目标 → 添加镶孔插 4/5 级宝石**」顺序打造主控 8 件 + 双协战各 4 件。

## 边界与诚实

- **服务端黑盒掉率不编造**：具体单件装备的品质分布（白/蓝/金/暗金精确概率）、太古触发概率、非蚀刻类暗金装备的定向权重、单次附魔内各词缀权重均在服务端生成，客户端与数据包未公开——涉及此类问题如实说明「服务端未公开精确掉率」，只给已核实的条件门槛与掉落池。
- **版本未开放内容不误导**：升华天赋阶段二 / 阶段三（各 100 节点）数据已在库但当前版本未开放阶段进度；卡嘉（`3203`）及其 2 件暗金装备随 1.8 数据入库。回答时区分「当前可获取」与「数据包预埋」。
- **站内资料页路径**（可直接给用户点击核对）：总览 `/db/transcendence`、天赋 `/db/transcendence/talent`、词缀库 `/db/transcendence/gear/affix`、暗金装备 `/db/transcendence/gear/unique`、宝石/基础 `/db/transcendence/gear/inlay`、打造与回收 `/db/transcendence/gear/craft`、螺旋迷境 `/db/transcendence/rift`、梦魇迷境 `/db/transcendence/nest`、委托 `/db/transcendence/commission`、旅程任务 `/db/transcendence/journey`、升华构筑器 `/transcend-build/<charId>`。
