# DOB 功能问答

本技能回答「DOB 客户端本身怎么用」：功能在哪开、前置条件是什么、失败时先查哪一步。不查游戏数值，**直接按下面对照表回答，不需要调用 `read_entry` / `query_module_entries` 等资料检索工具**（表里的 `/afk`、`/game-accounts` 是应用路由，不是资料库条目 `path`，不要拿它们去检索）。

仅一条需分适用方：若用户要你「看我当前这份构筑再说」——走配装助手的 `run_code` 读当前构筑；资料检索 Agent 请用户贴社区代码或截图后再答。

## 功能 → 入口速查

| 功能 | 入口 | 前置 |
|---|---|---|

| 小小狩月人同步 | 设置页「小小狩月人同步」卡片 | 仅桌面端，默认关闭；与官方 `AFKSupport.exe` 二选一 |
| 皎皎角账号管理 | 路由 `/game-accounts`（More → 皎皎角账号；侧边栏底部常驻） | 仅桌面端；网页端打开只显示下载 APP 遮罩 |
| 皎皎角登录框 | `/game-accounts` 点「添加账号」弹出的 `皎皎角登录` iframe | 选国服 / 国际服，邮箱或手机 + 验证码 |
| 局域网设备同步 | 设置 `/setting` →「局域网设备同步」 | 仅桌面端；先勾可信网络确认才能开；手机 App 配合 |

## 小小狩月人同步与狩月账本

- **互斥**：官方工具与本应用都当命名管道 `TBH_RewardPipe` 的服务端，同时开会抢事件流（先连上的一方拿满整条）。开启开关前先退出官方 `AFKSupport.exe`；要切回去就先关本应用开关再启动官方工具。
- **三态**：`未启用` / `运行中，等待游戏连接` / `已连接游戏`，另有 `已接收` 计数与 `最近事件` 列表。一直停在「等待连接」→ 进一次挂机委托场景或重启游戏（游戏只在进挂机场景时发起连接，不是持续轮询）。
- **回放不记账**：连接瞬间补发的历史事件只显示在事件流，账本从开启同步后开始记。
- **账本内容**（`/afk`）：完成场次 / 总掉落 / 金色掉落 / 场均掉落 / 累计时长；掉落趋势、品质分布、物品排行、副本产出、最近场次。时段筛 `今天 / 7 天 / 30 天 / 全部`，另有副本与品质筛选。品质只用颜色表示，名称只出现在筛选栏。
- **铸造产物**不属于副本，单独统计卡片（清掉副本筛选才看得到）；**迷津**在账本里显示为「迷津」。账本保留 90 天，清空要二次确认。
- **备份**：导出为 `{ version, exportedAt, runs, drops }` 的 JSON 文件；导入按自然键去重合并、只增不改。桌面通知（副本完成 / 铸造完成）与接收总开关独立，关通知不断记账。

## 皎皎角账号与登录

- **两种添加**：「添加账号」走登录 iframe（邮箱或手机号 + 验证码，`国服 / 国际服` 先选对）；「通过 JSON 添加」（列表右上角更多按钮，提示「通过 JSON 添加皎皎角账号（登录后可复制）」）。
- **JSON 形状**：`{ uid, name, dev_code, token, server: "cn" | "global", kf_token, refreshToken, pic, status, isComplete, isOfficial?, isRegister? }`，兼容 `userId / userName / headUrl / devCode` 别名；**必填只有 `uid`（或 `userId`）+ `token`**，`dev_code` 缺省自动生成，`server` 缺省按有无 `registerLang` 判国际服否则国服。同 `uid + server` 重新登录是**原地更新旧行**，不会多出一行。
- **账号行操作**：点行切换当前账号（切换后旧登录态吊销，后续请求用新 `token`）；复制 JSON；删除要二次确认。
- **隐私**：账号信息只存本地，不上传服务器。
- **未登录表现**：配装页导入游戏、库存同步、养成同步游戏、签到、社区帖子等统一提示「请先登录 / 请先登录皎皎角账号」或跳回 `/game-accounts`。先问用户当前在哪一步卡住，再指路。

## 局域网设备同步

- **位置与前置**：`/setting` →「局域网设备同步」。必须先勾「我确认当前处于可信的家庭或专用网络中……」才能开；描述原文明示仅建议可信家庭或专用网。状态分 `运行中 / 未运行`，运行时显示服务地址 `https://<本机IP>:28182` 与已配对设备列表。
- **端口**：HTTPS `28182`（证书获取、配对、状态查询、双向同步）、UDP `28183`（局域网发现）。桌面端没开开关时不响应发现。
- **配对流程**：手机 UDP 广播发现 → 拉取桌面自签 CA 并校验指纹（`SHA-256(caPem)` 必须等于通告里的 `caFingerprint`，否则按中间人处理并重走流程）→ 调配对接口后**在桌面端弹窗点允许**（等待最长 60 秒，手机端显示「请在桌面端确认」）→ 成功保存 token，此后免配对。同一设备重复配对会吊销旧 token。
- **同步内容**（一次请求双向）：DOB 社区账号（单账号，后推送方覆盖）+ 皎皎角账号列表（按 `uid` 合并，同 `uid` 推送方覆盖）。响应里的快照已含刚推上去的数据，直接用它刷新本机即可。
- **移除设备**后需重新配对。桌面端 DOB 登录态变化会自动刷新快照。
- **排障**：桌面关了开关 → `SYNC_DISABLED`；token 被移除 → `BAD_TOKEN`，清本地 token 回配对流程；桌面点了拒绝 → `PAIR_DENIED`；60 秒无人点 → `PAIR_TIMEOUT`，可直接重试；TLS 握手失败或指纹对不上 → 清已固定 CA 重走证书获取（多为桌面重装导致 CA 变更）。

## 各页「导入 JSON / 同步游戏」口径

- **两种通道别混**：剪贴板类（配装复制代码 / 剪贴板导入、库存导入 JSON / 复制 JSON、养成导入 JSON / 复制 JSON）读写的是**系统剪贴板**；文件类（账本导出 / 导入备份、成就导入 / 导出、脚本工具导入 JSON 文件）走的是**文件选择器（`.json`）**。用户说「导入没反应」先问他走的是哪个入口。
- **配装**（`/char`）：复制代码 = 当前构筑纯 JSON 进剪贴板；剪贴板导入 = 解析剪贴板 JSON 并归一化为当前构筑，格式不对报「不是有效的构筑文本」；导入游戏 = 按角色 / 武器 id 从游戏拉魔之楔（含中枢），失败多为没登录皎皎角账号。
- **库存**（`/inventory`）：导入 JSON 要求 `{ melee, ranged }` 都是对象，缺键或 parse 失败报「导入数据格式错误 / 导入失败」；同步模式三档为 `仅武器 / 武器和角色魔之楔 / 武器和角色武器魔之楔`，后两档先弹「扫描耗时」确认。
- **养成**（`/levelup`）：同步游戏拉全量角色信息后填表；导入 JSON 形如 `{ manual, breakthrough, extra }`，未知键删除、非法值回默认值；复制 JSON 进剪贴板；重置清空三组输入。
- **时间线**（`/timeline`）：导出 JSON / 加载 JSON，`导入JSON失败`多为文件格式不对；方案名已存在弹覆盖确认。
- **成就**：导入会覆盖当前完成记录，导入前有确认框；文件格式不对报导入失败。

## 常见提问 → 处理路径

| 用户怎么问 | 先说什么 |
|---|---|
| 小小狩月人在哪里开 | 设置页「小小狩月人同步」卡片，打开开关；与官方工具二选一，先关官方工具 |
| 狩月账本在哪里 | `More → 狩月账本`（`/afk`），仅桌面端；空账本先开同步并进一次挂机委托 |
| 同步开了但没数据 | 看设置页状态：等待连接 → 进挂机场景或重启游戏；看最近事件是否涨；回放历史不记账 |
| 皎皎角怎么登录 | `/game-accounts` 点添加账号，选国服 / 国际服，邮箱或手机收验证码；网页端不行，要桌面客户端 |
| JSON 添加账号怎么用 | 列表页更多按钮 → 粘贴 JSON（必填 `uid + token`），同账号重复贴是更新 |
| 切换账号不生效 | 点账号行切换当前账号；旧登录态已吊销，再重进功能页 |
| 局域网同步怎么用 | 设置里先勾可信确认再开 → 手机发现 → 校验证书 → 桌面点允许 → 一键同步 |
| 配对一直转圈 | 去桌面看弹窗点了允许没；超 60 秒按超时重试 |
| 导入 JSON 失败 | 先确认入口：剪贴板类重抄一遍（配装 / 库存 / 养成），文件类重选 `.json`；库存看缺不缺 `melee / ranged`，账号看缺不缺 `uid / token` |
| 同步游戏失败 | 先确认 `/game-accounts` 有账号且是当前账号，再重试同步 |
| 网页端为什么没有账本 / 账号 / 同步 | 这几个都是仅桌面端，网页端无数据源；下桌面客户端 |

## 边界与诚实

- 仅桌面端的功能（狩月账本、小小狩月人同步、皎皎角账号、局域网同步、解包）在网页端问起时直接说没有，不要给替代路径。
- 账本不做市价 / 金币估值、不做云端同步；要估值、要跨机同步（除局域网配对同步账号外）如实说没有。
- 版本更新后入口与文案可能变化，引用时以当前客户端实际文字为准；不确定的步骤说「以你客户端实际显示为准」，别编按钮名。
