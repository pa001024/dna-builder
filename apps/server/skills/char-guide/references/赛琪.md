## 一句话定位

风属性**同律武器主战输出**，社区称「对单天花板」。终结技（社区叫法 大招 / Q，即 [腐草为萤]）飞天变身，之后主要靠**同律武器 [伊卡洛斯] 的远程输出 + 背水（残血增伤）**打伤害；操作量极低（开大后长按普攻），社区戏称「轮椅输出」。**打击面口径（社区，2026-10）**：纯同律（射击）的打击面较窄，**偏向对单**；**对群环境社区多用登龙公式**（蓄力跳劈打击面大，见「分歧」）。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)。**社区口径（2026-10）：对群环境多用这条公式**（赛琪版即下方 `蒙恩御礼` 登龙流）；纯同律射击轴打击面窄、偏对单，两者按场景取舍。

## 机制读法（社区口径，用于理解提问）

- **破茧轴**：终结技 [腐草为萤] 进 [破茧]（飞天），破茧中只能用技能和射击。战技（社区叫法 E，即 [抽茧成梦]）在破茧中**被替换为 [逐光]** —— 发射 16 枚 [浮光鳞粉]、叠 [鳞粉印记]，靠**远程 / 同律武器伤害引爆印记** ⇒ 这是她「对单强」的来源。
- **背水**：破茧「有血烧血、无血耗蓝」，生命百分比越低背水收益越高。被动 [譬如朝露] 在指定条件下把「计算昂扬 / 背水时的生命值视为 1%」，即**一键吃满背水**。社区口径：背水实际增伤约为面板背水的 **3.75 倍**，是「能吃满时收益最高的词条」，但**收益不稳定，日常只带 1~2 张背水**。
- **增益数量**：被动 [萤烛微光] 暴击时随机给攻击 / 技能威力 / 背水，并按自身**增益数量**增伤（最多计 12 个）⇒ 社区据此认为「多挂增益」有额外收益。
- **技能效益**：清杂与跑图靠**自锁战技 [逐光]**，社区口径「至少带 1 张技能效益卡，联机至少 2 张」。⚠️ 1.6 戏剧帖补充：**开大时普攻也吃技能范围**，打小怪关要留意。

## 技能升级优先级

三种口径，方向一致（终结技 / 战技优先，被动其次）：
- **口径 A**：**全满**，`终结技 = 战技 > 被动`。
- **口径 B**：**终结技 > 战技 > 被动**。
- **口径 C**（v1.1 单）：抽茧成梦 Lv.10 / 腐草为萤 Lv.8~10 / 萤烛微光 Lv.8。

## 溯源取舍

核心 **1 / 2 / 6 溯**（多方一致）：
- **1 溯**：释放战技后回血 + 增伤 → 社区「单人质变」，缓解奶量压力、延长终结技续航。
- **2 溯**：破茧中每 5 秒自动补一轮 [浮光鳞粉]、且鳞粉 / 印记有概率生成 [幻象] → 清怪效率质变（社区口径约 **+30%~35%**）。
- **4 溯**：破茧中获得 [羽化]（不僵直 / 减伤 / 拾取范围）→ 手感与生存，非核心输出。
- **6 溯**：破茧中**全属性穿透 +50%** → 独立乘区，高难上限。
- 3 / 5 溯只加技能等级。
⇒ 方位：**0 溯能玩、1 溯质变、2 溯清怪、6 溯上限**。（溯源原文在 `read_entry`。）

## 已知疑点（社区未定论，不要当结论讲）

- **「普攻流 vs 战技流」口径反复**：二测 / 早期资料分「变身 + 同律普攻」与「变身 + 战技召唤」两派；社区（2025-11）并列两派；社区v1.1 出现「平 A 流已经没落」的标注（指代不明确）。而 社区与 2026 一图流主流仍是「**长按同律普攻 + 约 6 秒补一次战技**」⇒ 当前主流其实是普攻循环，「战技流」只在特定时期 / 跑图被提。
- **背水收益口径变过**：二测时期因「难以吃满」而主张放弃背水；现在因被动 [譬如朝露] + 1 溯回血 + 压血配卡而**重新吃满**，成为主推词条 —— 引用时务必标时间。
- **联机适配差**：社区「烧血无法减免，联机需持续清怪保持血蓝健康」。
- 社区数字（2 溯约 +30%~35%、专武「90% 技能威力」等）与数据包字段**不完全对齐**，**只作方向**。
- [鳞粉印记] 的引爆条件：数据包原文写「受到赛琪的**远程武器**伤害时」，部分站写「**暴击时**引爆」——**以数据包为准**。
