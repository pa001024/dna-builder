# 妮弗尔夫人（雾海引渡人）

> 数据包内名 **妮弗尔夫人**，`char id 1502`（属性 / 标签 / 精通 / 溯源原文都在 `read_entry char 1502` 里，本文件不重复原文）。数据包 `标签` = 输出 / 技能伤害，`精通` = 太刀 / 手枪；**`专武` 字段为空**。
> 版本：1.0。社区简称 **「夫人」**；⚠️ 社区攻略常把 **「无序奇点」** 称为她的「专武」，但**数据包 `专武` 为空** —— 与伊薇（旧称「艾达（？？）」）的情况类似，回答「夫人要不要专武」时先确认指的是哪一把。
> 本文件为**社区口径汇总**，配装结论**只作方向参考**。

## 一句话定位

光属性**群攻技能输出**（社区称开服期 **T0 群攻**）：靠**终结技 [雾海安魂]** 进入 [送葬] 状态换来「多次免神智的强化战技 + 技能范围转威力 + 聚怪」，用日 / 月双形态的战技刷特效出伤。**范围极大、不吃操作**，但对神智消耗大 ⇒ **前中期偏弱、需养成到后期**。

## 机制读法（社区口径，用于理解提问）

- 核心是 **终结技 [雾海安魂]**：开启后 [送葬] 状态下**多次（社区口径 6 次）强化战技免神智**，并把自身**技能范围转化为技能威力**，同时带聚怪。⚠️ 社区反复强调**终结技 120 点神智消耗是本角色的最大痛点**，「缺蓝」是配装主线。
- **战技 [月猎]**（日 / 月双形态）：铺范围伤害 + 减速 / 攻击降低类控制，并靠被动刷额外攻击。
- **被动 [啼鸣交织]**：决定 [月猎]/[日食] 额外效果的**触发概率（上限 65%）**；**1 溯后上限本身不变，但概率 +15%**，社区认为主要是**降低远程武器对触发概率的需求**。
- ⇒ 社区把它概括成「**开大 → 零消耗刷强化战技 → 范围转威力打群**」，6 溯后「远程武器也能概率生成特效」，从而**摆脱大招蓝耗依赖**。
- 属性需求宽（攻击 / 技能威力 / 技能范围都要），是「**养成多、成型晚**」的典型。

## 技能升级优先级

- **社区口径**：素材多时**全分支点满**；资源紧先到 8 级，再按 **十级战技 > 十级终结技 > 八级被动** 拉满；**被动 8 级即吃满，往上点是浪费**。
- **社区口径**：**战技 = 终结技 为核心（优先）**，其次被动 [啼鸣交织]，最低是 2 技能。
- **社区口径**：**技能优先点满战技与终结技**。
- ⇒ 一致点：**战技 / 终结技双核心优先**；分歧只在「被动要不要同步满」。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：[啼鸣交织] 效果概率 +15%（上限 65%）—— 社区口径：**降低远程武器触发概率需求**，本身增伤一般。
- **2 溯（质变）**：使 [月猎] / [日食] **互相给目标挂 75% 易伤**（打得越高越痛）—— 多方称「**纯粹的 75% 独立乘区增伤，输出基石**」。
- **4 溯**：自身受到的治疗 +50%、**神智回复 +25%**（并**向上取整**，如嗅盐回复 25 → 33）—— 纯**续航**档。
- **6 溯（质变）**：**使用远程武器造成伤害时，有 25% 概率生成 [月猎]/[日食]**（每秒最多 1 次）—— 社区口径「**蓝耗质变，减少对终结技的依赖，持续作战能力加强**」；注意生成的 [月猎]/[日食]**吃不到终结技增益，但能触发被动**。
- ⇒ 结论口径（多方一致）：**核心溯源 1 / 2 / 4 / 6；其中 2 溯质变、6 溯质变**。养成建议「55 历练后刷满 6 溯」。
