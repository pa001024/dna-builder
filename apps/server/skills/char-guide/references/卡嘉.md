# 卡嘉（群氓的牲王）

> 数据包内名 **卡嘉**，`char id 3203`（属性 / 标签 / 精通 / 专武 / 溯源原文都在 `read_entry char 3203` 里，本文件不重复原文）。`专武` = 远程 · 手枪 **「天才的狂想」**（`read_entry weapon 20105`）。
> 版本：**1.8 新增**。数据包 `标签` = 输出 / 技能伤害 / **辅助**；精通 = 鞭刃 / 手枪，额外精通 = 单手剑 / 长柄 / 双刀 / 太刀。
> 本文件按**辅助口径**写：她是火队的技能拐（协战位），不是站场主 C。机制结论来自数据包字段与推导，线上**暂无**分享构筑可参照。

## 一句话定位

火属性**技能拐 / 协战副 C**。终结技「猫猫头出击！」放 3 座 [猫猫头炮台]，按模式给**全队**技能速度 / 攻击速度 / 火属性伤害；炮台还会给敌人挂 [灰烬标记]，由**队友的火属性伤害**触发卡嘉的追加伤害。拐力 = 模式增益 ＋ 协战被动 `奇技`（全队技能伤害 +10%）＋ 专武给全队的多重（对武器轴 / 多重系队友）。

## 在火队里的作用（辅助口径 · 1.8）

- **模式增益是主菜**：三种模式对「卡嘉自身及友方单位」提供不同增益 —— 速射 = 技能速度、贯穿 = 攻击速度、轰炸 = 火属性伤害。数值按 **Q 等级**成长：

| 模式 | 全队增益 | 数据包区间（技能等级 1→30） | 备注 |
|---|---|---|---|
| 速射 | 技能速度 | +20.6% → +154% | 技能速度有 **280% 全局上限**，会和其他来源抢 |
| 贯穿 | 攻击速度 | +34.8% → +261% | 偏武器轴队友 |
| 轰炸 | 火属性伤害 | +31.8% → +84% | **火队技能拐的默认档** |

- **`奇技`（协战被动，仅协战位生效）**：自身和队友**造成的技能伤害 +10%** —— 条件最低的一条，进队即生效 ⇒ 按辅助口径，主推位是**协战**；主控位会丢这 10%，但能自己控炮台。
- **[灰烬标记]（被动）**：炮台造成伤害时给目标挂标记；目标受到**来自卡嘉友方**的火属性伤害时触发，卡嘉追加 1 次技能伤害（Lv.30 **3748%** 技能威力，是她单次倍率最高的一段）。触发后 2 秒内不能再次施加 ⇒ **单目标上限约 0.5 次/秒**（推导），队友火伤频率与敌人数量决定收益。
- **与 `卡米拉` 的分工**（同属火属性协战拐，别写混）：
  - 卡米拉：协战被动给自身与火属性队友**昂扬**；**7 溯**给全队**火伤 +35%** ＋ **技能伤害无视目标 30% 防御**（10 秒窗口）—— 稀缺的减防。
  - 卡嘉：模式给**技能速度 / 攻速 / 火伤（Lv.30 +84%）** ＋ `奇技` **技能伤害 +10%**；**6 溯的 50% 全属性穿透只作用于自身**，不是全队减防。
  - 两人的副 C 线都靠**队友火属性伤害**兑现（卡米拉耗 [酒红伤]、卡嘉触发 [灰烬标记]），同一套火队可以同时吃两条；卡嘉 4 溯还会把标记触发转成 [火属性紊乱]，顺手喂 `焚炎紊乱` / `法露茜`。

## 机制读法（用于理解提问）

- **双资源维持**：炮台存在时每秒消耗 **20 神智 + 20 毁灭灵感**；神智降到 0 或长按终结技召回。灵感上限 600，每次释放 E +30。
- **窗口有限，不是常驻光环（推导）**：基础神智 200；按配装模型口径，自然回复 =（2 + ⌊最大神智/200⌋）每 3 秒 = **1/秒**，净消耗约 19/秒 ⇒ 基础档炮台只撑 **约 10 秒**。每秒神智消耗这条的 `属性影响` 是 `技能效益`、`技能耐久`（两者都作用于持续耗神智类技能的每秒消耗；上限分别 175% / 400%），神智词条再抬高上限 —— 做拐要算的是**覆盖率**，不是面板。
- **[毁灭灵感] 的三个门槛**：>0 → 炮台增伤（Lv.30 **+148%**）；**>300 → 6 溯的 50% 全属性穿透**；600 为上限。600 起手按 20/秒掉回 300 约 **15 秒** ⇒ **6 溯穿透是有窗口的**（E +30 / 1 溯武器触发 +2 回填）。
- **模式切换与续位**：短按终结技切模式、长按召回；炮台离卡嘉 >20 米时释放 E 会在卡嘉当前位置重造炮台。
- **灰烬标记只认友方火伤**：没有火属性队友时标记挂了没人触发，**副 C 线直接塌掉**（辅助线仍在）。单人 / 无火队时别按双线收益预期。
- **两条「协战」技能别混**：`奇技` 写明「仅在作为协战同伴登场时生效」；`燃起来了！` 虽然也归在协战技能表，但原文没有这句限定。
- **不适配「太刀登龙 + 棘刺绝响」通用公式**：精通（鞭刃 / 手枪）与额外精通都不含**突击枪**，`棘刺绝响` 的灾厄熔炼对她不生效；反过来说，额外精通含**太刀**，1.8 灾厄太刀 `限界无明` 的灾厄熔炼对她生效，但她的出伤主体是技能（炮台 / 标记），不是武器轴 —— 线上无样本，不作推荐。
- 字段落点：三模式增益 / 炮台倍率 / [毁灭灵感] 增伤 / 灰烬标记倍率都在 `read_entry char 3203` 的 `技能字段`；三种模式的文字定义在同条 `技能术语解释`。

## 技能升级优先级

- **辅助轴：Q > 被动 > E（推导）**：三条模式增益全部挂在 `猫猫头出击！` 的字段上、按 Q 等级成长 ⇒ **Q 是她拐力的总开关**；被动决定 [灰烬标记] 倍率（502.9% → 3748%）；E 只抬自身炸弹直伤与削韧，辅力不变（每次 +30 灵感是固定值）。
- **副 C 轴：Q 与被动都要吃投入，E 最后**：Q 决定炮台持续出伤，被动决定 [灰烬标记] 的单次倍率（两者都随技能等级放大）。
- **溯源 3 / 5 等价技能等级**：3 溯 E+2 / 被动+1，5 溯 Q+2 / 被动+1 ⇒ 追拐力时 5 溯的 Q+2 更对口（溯源须按顺序，实际是 5 溯顺带吃 3 溯）。

## 溯源取舍

- **1 溯（循环件）**：开局 300 灵感；武器攻击触发属性额外效果时 +2 灵感 ⇒ 落地就能吃炮台增伤、6 溯穿透立刻在线。没有它，灵感从 0 起，得靠 E 一发发攒。
- **2 溯（自身输出，别按满值预期）**：自身技能伤害 = **多重射击 × 6%，上限 30%**；换算门槛是 **多重 ≥ 500%** 才吃满。专武满层的团队多重（62% / 125%）单独代入只有 **约 3.7% / 7.5%**，普通拐装的总多重远不到 500% ⇒ 这一溯的自身增伤是个位数到一成多，别按 30% 预期。
- **4 溯（团队向）**：[灰烬标记] 触发时给目标补 1 层 [火属性紊乱] ⇒ 喂 `法露茜` 的战技结算（消耗 3 层）与 `焚炎紊乱`（消耗紊乱叠增伤，最多 5 层）。单目标产能约 0.5 层/秒，属顺手供层。
- **6 溯（自身穿透）**：灵感 >300 时**自身** 50% 全属性穿透（不是全队）；配合 1 溯开局 300 可立即触发，灵感掉到 300 以下即失效。

## 队友

- **需要高频火属性伤害的队友**才能兑现 [灰烬标记]（以及 4 溯的紊乱供给）：`法露茜`、`希尔妲`、`琳恩`、`卡米拉` 都在火属性出伤位上；`卡米拉` 还有 7 溯的全队火伤 +35% / 技能无视 30% 防御，与卡嘉的模式增益分属不同乘区。
- **三火队方向（1.8 机制推导，非线上构筑）**：主控 `希尔妲` ＋ 协战 `卡嘉` ＋ 协战 `卡米拉` —— 两个协战被动（`奇技` 技能伤害 +10% / `瑰色裙裾` 昂扬）都能覆盖同属性主控；主控近战可用 1.8 灾厄太刀 `限界无明`（希尔妲额外精通含太刀），卡嘉与卡米拉只提供增益与副 C。**这是字段推出来的组合，不是站上构筑，别当推荐配装引用。**
- 单人 / 无火队友：辅助线（模式增益 + `奇技`）还在，**副 C 线基本不产出**。

## 已知疑点

- **协战 AI 行为**：模式增益与炮台都要求先开 Q、再选模式；AI 在协战位是否主动维持，数据包不描述 AI 行为、线上又无样本 ⇒ 需实测。若 AI 不开 Q，她只剩 `奇技` 的 +10%。
- **「友方单位」的边界**：模式增益原文是「卡嘉自身及友方单位」；是否覆盖协战同伴 / 召唤物，数据包不细分，引用时按原文说「友方单位」。
- **专武叠层速度**：需要「技能伤害触发额外效果」，`燃起来了！` 的概率 = 远程武器触发概率（专武 33%）；炮台高频下的实际满层时间未实测。
- **1.8 升华专属**：`爆破天才战靴`（终结技 +10；改为亲自操控炮台，三模式倍率 +319.3% / +408.9% / +508.2%）与 `爆破天才项链`（被动 +10；灵感 >300 时炮台耗紊乱追加 700% 火充盈伤害）把她从拐改成主 C —— 那是**升华构筑口径**，见 `into-slumber` 技能，别混进普通配装。
