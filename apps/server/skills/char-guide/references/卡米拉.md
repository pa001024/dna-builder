## 一句话定位

火属性**技能输出 / AI 协战副 C**，社区俗称「老板娘」。用终结技「赤霞珠舞」召唤环绕的 [开酒刀]，长按战技「猩红欢宴」击飞开酒刀挂 Dot [酒红伤]，靠**移除 Dot 的伤害**出伤。

## 在法露茜队里的作用（副 C 口径 · 1.6）

> 按《法露茜》攻略（2026-10 成稿）的既定口径简述；「属克」= 敌抗性 −4。本页 ★ 推荐构筑正是该攻略里卡米拉副 C 的取数口径（模型复算属克 **12.56 亿** / 无属性 **2.51 亿**；作者标注 13.45 / 2.69 亿）。

- **双重身份**：作为**协战同伴**挂 AI 位自己出伤（副 C），同时给全队喂增益。她给法露茜队的增益只有两条，且都是**通用乘区**（不属于技能 / 武器任何一侧的专属词条）：
  - **协战被动 `瑰色裙裾`**（仅在协战位生效）：自身与火属性队友**昂扬提高**（法露茜攻略口径 +15%）；
  - **7 溯**：移除 [酣畅淋漓] 时，自身和队友获得**造成火属性伤害提高 35%** ＋ **造成技能伤害时无视目标 30% 防御**，持续 10 秒，队友另回复 5 点神智（数据包 7 溯原文，`read_entry char 3202` 可查）。
- **7 溯是进队核心理由**：技能伤害无视防御是稀缺词条。月阶 1000 防御定制怪场景，**月阶场地 40% ＋ 卡米拉 7 溯 30% ＋ 扶疏 1 溯 30% 同池线性相加 = 100% 满破**（减防有效上限 100%，防御乘区 0.23 → 1.00）；缺她只剩 70%，伤害约腰斩 ⇒ 该期月阶**必带**（法露茜阵容榜：扶疏＋卡米拉断档第一）。减防叠加的推导链见 `references/法露茜.md`「机制 · 技能无视防御」节。
- **运转前提**：她「自己挂 Dot、自己耗 Dot」两头兼顾不了——[酒红伤] 要靠**队友的高频火属性伤害**来移除，移除者攒被动 `迟迟醉醒` 的 [酣畅淋漓]（20 层一清）。法露茜 / 希尔妲在队里干的正是这个活；主 C 轴则靠 `菲娜` 属性转换＋火追伤触发。
- **副 C 输出几乎全挂在属克上**：作者标注属克 13.45 亿 → 无属性 2.69 亿（缩水约八成）。**非属克环境她主要剩 7 溯减防 / 昂扬的辅助价值**，副 C 输出别按属克数字预期。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- 核心耦合：**卡米拉自己挂 Dot（开酒刀）、自己耗 Dot，无法两头兼顾** ⇒ 社区一致口径「**必须配一个高频火属性伤害的队友**去触发 [酒红伤] 移除」。
- **社区口径**：卡米拉定位≈「火队里的煜明」，**AI 表现非常稳定**，适合放协战位补伤害；1.3 时点「没有频率够高的火系队友（女枪都不行）」处于**冷板凳**——1.4 起 `希尔妲`、1.6 起 `法露茜` 相继接上（见「作用」节与「配装」节）。
- **属性堆叠（社区口径）**：**技能范围只影响战技本身、不影响主要伤害源 [开酒刀] 的范围，无需高堆**；**技能耐久影响 [开酒刀] 持续时间，但放战技时 [开酒刀] 计时暂停，也不用堆** ⇒ 能堆的只有 **技能威力与技能效益**。

## 技能升级优先级

- **社区口径**：**被动建议满级，终结技、战技 8 级或满级**。
- **社区口径**：**被动优先 > 终结技 > 小技能**（被动直接提 [酒红伤] 额外伤害倍率；战技最后升）。线上推荐系三套均为角色 L80 / 技能 L12。
