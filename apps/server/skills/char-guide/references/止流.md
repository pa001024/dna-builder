## 一句话定位

雷属性**技能爆发主 C**：战技攒〔泉符〕、终结技按符组合成三种形态爆发。**开 7 溯后转「卦象·震有声」循环**——不再切三形态，而是双〔震〕→ 震有声连打，吃 1 溯联动 + 7 溯紊乱增伤，输出重心全移到这上面（震有声 + 相与 + 7 溯三项占总伤 96.0%，★推荐 1.7 构筑本地复算口径）。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通含突击枪**（配装时把额外精通选成突击枪，灾厄潜能门槛才成立），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与专属流派孰优，以本文件构筑口径为准。

## 机制联动（这条链懂了，7 溯流就懂了）

1. **攒符**：战技 `解天机` 点按 →〔解天机·震〕+ 1 枚〔泉符·震〕；长按 →〔解天机·巽〕+ 超限护盾 + 1 枚〔泉符·巽〕。纯攒符工具，本身倍率低。
2. **符 → 形态**：终结技 `天地演绎` 持 2 符时按组合替换——双震 = **震有声**（前方 12×6 米直线爆发、出伤快，但打多动症单目标易空）；震 + 巽 = **万物生**（铺 20 米〔雷风齐四方〕领域 24 秒，领域每 3 秒选敌生成〔雷风相与〕）；双巽 = **天地明**（自身增伤）。
3. **领域是总枢纽**：〔雷风相与〕是领域里的持续出伤线；**1 溯**让每次震有声额外触发一次相与效果（每道 60% 伤害，2 溯选敌 8 名 ⇒ 8 道）；**6 溯**在领域内给全属性穿透 +40% 且常驻〔天地明〕增伤；**7 溯**满层让领域**时间暂停（永续）**。
4. **7 溯闭环**：连续释放相同的战技或终结技叠〔卦象〕（每层技能速度 +6%、无视防御 +6%，10 秒、最多 5 层）→ 满层后相与命中**消耗目标 1 层〔雷属性紊乱〕、倍率 +600%×充盈威力** ⇒ **充盈威力是 7 溯的放大器**（这就是角色槽堆 `充盈·巧力` + `炽灼·精炼` 的原因）。
5. **两条被动**：`双泉并舞` 移除符时逐个判定保留（L12 = **58% + 50%×近战触发概率**，满触发 108% 封顶 100%）⇒ 近战堆缠缚系；`相生` 自身与队友造成雷伤叠昂扬（每层 1.5%、20 层）⇒ **强绑雷属性队友**。
6. **4 溯**：回神导致神智**溢出**时给自身与队友叠攻击提高 16%（5 层）⇒ 神智 / 回神不能断档。

⇒ 一句话：**卦象 5 层 → 领域永续 → 1 溯 / 6 溯全程不断 + 相与吃紊乱增伤**；紊乱供给是命门（见「已知疑点」）。

字段落点：三形态倍率 / 领域半径与时长在 `read_entry char 4102` 技能.字段（`[震有声]伤害` / `[万物生]伤害` / `[雷风相与]伤害` / `[雷风齐四方]领域*`），神智消耗同段；保符概率看被动 `双泉并舞` 的 `效果概率`；溯源 7 条原文在 `溯源` 字段。

## 手法（7 溯循环，当前构筑的计算前提）

**起手（只打一次）**：点按 + 长按 → 万物生铺下领域 → 进循环。**不需要双巽 → 天地明起手**：6 溯在领域内直接常驻天地明增伤，铺下领域就等于自带。

**循环**：点按 + 点按（双〔震〕）→ 震有声 → 重复。全程同一套招 ⇒ 卦象 5 层轻松常驻（技能速度 +30%、无视 30% 防御；实测面板技能速度 +126%，即属性值 2.26，模型内上限 280% 未顶满），满层后领域永续 ⇒ 1 溯（每发震有声 8 道 60% 相与）与 6 溯不断电。震有声内置间隔 `2/(1+技能速度)`（解包精确值，随技能速度缩放；+126% 时 ≈ 0.885 秒）——`天地演绎` 本体虽带 cd 2.5 秒，但三个替换子技能（震有声 / 万物生 / 天地明）均 **0 cd**，循环节奏不受大招 cd 限制。

**三个命门**：

- **神智**：每轮循环 75 点（震有声 45 + 战技 15×2），靠 `扶疏Q` + `紫晶艾尔芙` 主动（回神智）顶着；一断 4 溯先掉（攻击 -80%）。
- **保符**：`双泉并舞` 逐个判定保留（L12 = 58% + 50%×近战触发概率，满触发 108% 封顶 100%）。本构筑近战缠缚系 mod 把触发率堆到 **248%**，保符率 132% 封顶 ⇒ **每个泉符都必留**，循环里符永远够用，点按只用于攒双〔震〕。
- **紊乱**：7 溯每跳要吃 1 层雷属性紊乱，构筑按 2.5 层/秒**手写**——供给侧数据包未建模，覆盖率掉下来 7 溯那 43.2% 先打折。

## 7 溯：整套玩法的地基

- **前置**：溯源先到 6 级，再消耗五类材料（数据包 `第七溯源消耗`：`思绪片段·止流` ×30 / `凝合思绪·止流` ×1 / `暮夜的履迹` ×2 / `血清注射器` ×5 / `瓶中闪电` ×20）；材料限时兑换属运营信息，**会过期，勿当现状**。
- **收益**：单撤 `止流7溯` buff 实测 **-21.4%**，`[7溯]DPS` 一项占总伤 **43.2%**。**没开 7 溯不要用本文件主控位的配装与循环**（未开时是三形态切换打法，同协战位见专节）。
- **队友侧的 7 溯**：`煜明7溯` 的层数 = **队内雷属性角色数量**。本队止流 + 煜明两人（扶疏是水）⇒ **只有 2 层**，三雷队才 3 层；★存档按 **3 层**计（取 2 层时 -7.5%，见消融；两份 1.7 挂机稿是三雷，3 层合法）。需煜明放出强化战技〔星河寥落〕才挂〔玄蛟庇佑〕，此处按常驻计。

## 溯源分工（默认 1–6 全开，7 溯以全溯为前置）

- **1 溯**：震有声额外触发 8 道 60% 相与 ⇒ 直线形态增伤，循环的发动机（表达式 `[震有声及1溯]伤害` 的后半段）。
- **2 溯**：万物生点按版选敌增至 8 名 ⇒ 表达式 `相与×8/3` 的前提；长按永续领域（每秒 6 神智）是备选，不在当前循环。社区按释放方式戏称：**点按 = 黑龙，长按 = 白龙**。
- **4 溯**：神智溢出叠 16% 攻击 ×5（构筑取满）⇒ 扶疏回神 + 魔灵主动的续航变得关键。
- **6 溯**：领域内全属性穿透 +40% + 持续获得天地明增伤 ⇒ 起手省掉双巽；7 溯冻结领域后等于常驻。
- **7 溯**：卦象 + 永续领域 + 相与吃紊乱增伤，见上两节。
- 未开 7 溯的旧循环（社区口径）：开场两个长按战技 + 终结技攒增伤 →「短 + 长 + 大」→ 之后「短 + 短 + 大」按三形态切换；6 溯可省第一步。**协战位（自律 AI）实际就打这套**，见「协战位」节。

## 已知疑点（社区未定论）

1. **雷属性紊乱的供给侧未建模**（最大待验证点）：7 溯每跳吃 1 层，构筑按 2.5 层/秒手写；数据包只写消耗侧（7 溯、血染·抽丝等），谁挂紊乱、覆盖率能否撑住需实战确认。
2. **近战 3 空槽待补**（现 5/8 件，耐受只剩 3 点）：补件只能选低耐受且名称 / 系列不冲突的，补前重算耐受。
3. **AI 挂机口径分歧**：一说 AI 不续保符、只按「2 符 1 大」频率丢技能，不如主控（但本构筑保符必成，此条影响有限）；一说其施法顺序「天地明 → 万物生 → 震有声」偏慢、真空期大。**两种并列**。
4. `衰朽+2`只拉等级不改系数 DPS 零变化——羽化线再怎么拉也只是添头（旧基线下系数同步改 1.0 仅 +1.8%），配装先保角色槽与近战补件。
