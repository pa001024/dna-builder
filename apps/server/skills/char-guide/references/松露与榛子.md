## 一句话定位

风属性**辅助 / 最大生命 / 治疗**，社区公认的「**固定二号位 / 通用奶妈**」。战技（社区叫法 E，即 [蹄蹄小跑]）**无条件给全队治疗 + 增伤**，被动给风属性角色**加背水**（社区「风系专拐」，目前主要拐赛琪 / 奥特赛德）；本身伤害低，做纯辅助养。

## 机制读法（社区口径，用于理解提问）

- **[蹄蹄小跑]（战技）**：**角色价值几乎全在这一招**。释放即为自身和队友**治疗 + 附加「造成伤害提高」**（社区读作「无条件增伤」，数值高且泛用）。长按 → 骑乘冲刺 [蹄蹄大冲撞]。
- **[饱饱工作]（终结技）**：骑乘 [榛子] 获得 [工作热情]，骑乘中**无法使用武器**、可指挥榛子攻击；[工作热情] 耗尽或再次释放 → 退出并**自动补放一次 [蹄蹄小跑]**。⇒ 联机循环（社区口径）：**放战技 → 开终结技 → 一直拱 → [工作热情] 快没时长按战技 → 循环**。
- **[忙忙粮秣官]（被动）**：移动叠 [重磅人物]（增伤 + 减伤）⇒ 社区「**保持移动是玩好她的关键**」。
- **[连连补给]（被动）**：概率产 [弹药补给箱]，是 6 溯的触发道具（社区）。
- **[咕咕觅食]（协战）**：队内 ≥2 同属性 → 自身和队友**背水提高**。
- 属性口径：松露**只吃生命和技能威力**（攻击力不加技能倍率，只加一点属性攻击）⇒ 有效词条 **生命 > 技能威力 > 攻击力**。

## 技能升级优先级

- 社区一致：**战技满级，终结技 / 被动 6~8 级即可**；材料不足**只升战技**。理由：价值全在战技的增伤 + 治疗。

## 溯源取舍

- **2 溯**：释放技能时为队友附加「攻击提高」（数值随松露**最大生命**、有上限）。社区认为「团队增益最关键」；但 社区提醒**需要约 1 万生命才吃满、且 300 点攻击提升有限**，建议「大后期主 C 都养完再回头补」。
- **4 溯**：被动 [重磅人物] 叠加上限提高、且上猪即满层 → 社区称**核心质变 / 起手节奏**。
- **1 溯**：[工作热情] 下降速度降低（延长骑乘）。
- **6 溯**：拾取补给类道具后叠技能威力 → 社区「用 **摇摇火尾** 可直接叠满三层」（需 [连连补给]）。
- 3 / 5 溯只加技能等级。
⇒ 方位：**0 溯即用；2 溯给全队攻击；4 溯手感 / 起手；6 溯厨力向**。
