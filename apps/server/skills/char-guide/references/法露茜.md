### 两条出伤线：技能流 vs 武器流（贯穿全局的口径）

社区说的「技能流 / 武器流」= **这套配装把资源砸在哪条结算线上**。法露茜只有两条互不相通的线，
**判据是 `技能字段` 行末的 tag ＋ 该行的 `影响`，不是字段名**：

| 流派 | 走哪套结算 | 判据 | 法露茜侧的条目（`read_entry char 3104`） |
|---|---|---|---|
| **技能流** | 技能伤害 | tag 含 `技能`（再配 `战技` / `终结技`），`影响 = 技能威力` | `潜入夜色`(310401) 的 [暗影一刺] / [暗影奔袭]；`坠入黑渊`(310402) 的 伤害 / `充盈伤害` / `附加伤害`；被动 `浴血`(310404) |
| **武器流** | 武器伤害 | tag = `["远程","武器","充盈"]` | 远程灾厄武器 **血染织羽(20298)** 的 [羽化] 子弹（见推导链 3） |

⚠️ **tag 里有没有 `技能` 是唯一硬判据，名字不算**，这是最典型的错判：

- `坠入黑渊` 有一条字段就叫 **`充盈伤害`**（0.16 → 0.49），但它 tag 是 `["技能","终结技","充盈"]` ⇒ **技能伤害**，不算进 [羽化] / 灾厄那条线。
- [羽化] 的输出叫「灾厄伤害」，tag 却是 `远程/武器/充盈` ⇒ **武器伤害**。
- **`充盈` tag 只表示「这段伤害整体再 ×(1 + 充盈威力)」**，不代表它属于武器线 —— 技能流的 `充盈伤害` / `附加伤害` 同样吃充盈威力。

⇒ 一句话：**看 tag 不看名字**。

### 队友 / 辅助增益：只有三种作用域（做配装对比的核心口径）

**任何团队增益只可能落在三个笼子里**，别把通用乘区算成某一流派专属：

| 作用域 | 属性名 | 典型条目 |
|---|---|---|
| **技能侧专属** | 技能伤害 / 技能威力 / 技能速度 / **技能无视防御** | 扶疏助战 `技能伤害 +10%`、扶疏被动 `每层技能速度`（满级 13.8%，最多 2 层）、扶疏 Q 技能威力、扶疏 1 溯 `技能无视防御 +30%`、卡米拉 7 溯 `技能无视防御 +30%`、泽世的慈雨(队友) `技能伤害 +34%` |
| **武器侧专属** | **武器伤害** | **菲娜助战 `武器伤害 +10%`** —— 常用武器流辅助里**只有这一条**是武器专属 |
| **通用（两流派都全额吃）** | 攻击 / 增伤 / 属性穿透 / 背水 / 昂扬 / 属性伤害 | 卡米拉助战 `昂扬 +15%`、松露与榛子助战 `背水 +5%`、菲娜被动+1溯 `增伤 +45%` ＋ `属性穿透 +24%`、松露与榛子 E `增伤`（12 级 = 103%）、松露与榛子 2 溯 `固定攻击 +300`、榛子大冲击 `背水 +22%`、卡米拉 7 溯火属性增伤 +35%、织梦的白羽(队友) 攻击每层 +18% |

⇒ 推论（口径，不是数值结论）：**武器流的队友门槛几乎只有「有没有菲娜」**，多数组队差异落在**通用池**；
**技能流则高度依赖「技能伤害 / 技能速度 / 减防」这三条**，换队的落差比看起来大得多。

#### 怎么查（两层的工具面不一样）

1. **协战位**（每个角色的第 5 条技能，`类型: 协战`）—— `read_entry char <队友id>` 直接读得到，
   菲娜 / 扶疏 / 卡米拉 / 松露与榛子 四条助战的数值都是这么来的（**协战技能名常被多个角色共用，看字段值别看技能名**）。
2. **更深一层**（Q / 被动 / 溯源 / 队友武器）登记在**局内 BUFF** 里，**资料检索模块的 `read_entry` 读不到**；
   需要精确数值时到配装侧（BUFF 面板）确认，**不要凭记忆报数**。

#### 归属规则：BUFF 的 id 指向它的来源

- **来自角色的 BUFF：`id` = 角色 id**。`榛子大冲击`(5101) 名字听着像独立招式，实则属于**松露与榛子**（5101）；
  `菲娜助战`(1801)、`卡米拉7溯`(3202)、`扶疏1溯`(2401) 同理。
  ⇒ **做「撤掉某个队友」的对比时，必须把 id 相同、名字看不出来源的条目一起撤**（漏撤 `榛子大冲击` 会高估松露组）。
- **来自队友武器的 BUFF：名字带「(队友)」后缀，`id` = 武器 id** —— 泽世的慈雨(队友) 10502 `技能伤害 +34%`、
  织梦的白羽(队友) 20509 攻击、孤子的缚锁(队友) 10102、罪愆的逆鳞(队友) 10203 `技能伤害 +50%`、弧光百劫(队友) 20602。
  ⇒ **换一个队友要看两处**：该角色的协战 ＋ **他手里那把武器**。
- 条目带 `限定: <角色id>` 的（如 `法露茜Q` / `卡米拉E` / `菲娜4溯`）**只作用于本人**，不进队友池。

#### 前置条件写在描述里，默认不成立

组队问答**先把条件摆出来让用户自查**，不要默认生效：

- 扶疏助战 / 松露与榛子助战：**队内 ≥2 名属性相同的角色**（法露茜 = 火，同为火的是卡米拉）⇒ 双火队即满足。
- 菲娜助战：**「精通武器包含单手剑或突击枪」的队友** —— 而法露茜 `精通` 只有 **双刀 / 双枪**，
  所以线上构筑是靠把 **`额外精通` 选成「突击枪」** 来卡的（`read_entry char 3104` 的 `精通` 可核）。
- 卡米拉助战：**仅在作为协战同伴登场时生效**，且只给**火属性**队友（法露茜是火 ⇒ 成立）。

#### 为什么两组常用队友手感不同（定性）

- **扶疏线给的是「技能速度」**（被动 `神归心舍`：自身及队友**释放战技 / 终结技**后叠层）
  ⇒ 抬的是**出手频率**，短窗口 / 共斗 / 速切场景更值钱。⚠️ 「释放战技 / 终结技」只是**覆盖率条件**，
  **别写成「开得越勤它越猛」**——那是把因果讲反。
- **松露与榛子线给的是「增伤 / 背水」**（E ＋ 榛子大冲击）⇒ **持续型**，长桩吃满；它不给出手频率，短窗口吃不到全额。
- **菲娜线是唯一的「武器伤害」来源**（另一半是增伤 / 属性穿透，属通用）⇒ 判定顺序很干脆：先看「有没有菲娜」，再比较其余队友的通用收益。
- 要具体数字对比**请实算**，本文件不提供任何 DPS 数值。

### 技能无视防御：同池线性相加，硬顶 100%

这条决定了「技能流为什么挑关卡」。⚠️ **`技能无视防御` 只对技能伤害生效**（轮到它参与的正是上面那条技能线），武器伤害结算用不到它。

`狩月人之阶6`（月阶场地：充盈威力 >100% 后每超 100% → 无视 4%，**最多 40%**）＋ 卡米拉 7 溯 30% ＋ 扶疏 1 溯 30%
⇒ 三样叠满 = **100%**，防御最低削到 0，**超出 100% 完全无效**。

换算 `def = 敌人防御 × (1 − 减防)`、`减伤 = def / (300 + def − 等级差×10)`（等级差 0）：

| 减防 | 1000 防御目标的伤害乘区 |
|---|---|
| 0% | 0.231 |
| 40%（只吃场地） | 0.333 |
| 70%（任一两样） | **0.500** |
| 100%（三样齐） | **1.000** |

⇒ **缺一个减防源，乘区就从 1.0 掉到 0.5**：这类高防御定制主题不是「带谁更强」，而是**少谁就不成立**。

### 推导链 1 · 掉血上限 24%/s（最常被问的换算）

数据包里只有两条**散点原文**，没有「24%/s」这个数：

- **近战**：`技能术语解释` 的 [执行者] —— 「使用双刀武器造成伤害时，消耗 **5% 最大生命值**……消耗的生命值会在 **5 秒内逐秒扣除**，**最低扣除至 30%**」。
- **远程**：魔之楔 **`衰朽`（43343）** 的 `效果` —— 「造成远程武器伤害时，自身生命 ≥ **35%** 时**流失 10%**，每 **1.0 秒**最多触发 1 次」（精 5 = 1.0 秒）。

**推导**：

| 来源 | 换算 | 上限 |
|---|---|---|
| 近战 | 一次自费 5%，可从 100% 掉到 30%（扣到 30% 即停），最小循环 5 秒 ⇒ `(100% − 30%) / 5s` | **14%/s** |
| 远程 | 每次 10%，每 1.0 秒最多 1 次 ⇒ `10% / 1.0s` | **10%/s** |
| **合计** | 两条各打各的上限 | **24%/s** |

> 口径提示：近战那条的 14%/s 是**机制设计上限**（受 30% 地板与 5 秒扣血窗口共同约束），
> 不是「5% ÷ 击」。用户问「为什么最多 14%」时就用这个式子解释。
> 远程那条看的是**魔之楔等级**（ 5.0s → 间隔 1.0s），不同等级上限不同。

### 推导链 2 · 掉血 → [羽化] 层（换算率）

需要三条原文：

- 武器 `灾厄熔炼` **Lv.0 `血染·蜕变`**：造成伤害 → **+1 灾厄值**（上限 200）；满 100 → 消耗 100 换 **1 层[羽化]**（≤10 层）。
- 武器 `灾厄熔炼` **Lv.1 `织羽·剥茧`**：每损失 **0.5% 最大生命 → 5 灾厄值**。
- 武器 `灾厄熔炼` **Lv.1 `血染·抽丝`**：消耗属性紊乱 → **消耗层数 × 4** 灾厄值。

**推导**：`每 1% 生命流失 = (1 / 0.5) × 5 = 10 灾厄值 = 0.1 层[羽化]`
⇒ **每秒掉血百分比 × 10 = 羽化层/秒**。掉血 24%/s ⇒ 2.4 层/s。
⇒ 对照量级：一条命掉完（可掉 70%）≈ 7 层；而消耗 3 层[紊乱] 只有 0.12 层 —— **掉血是量级上的主料**。

### 推导链 3 · [羽化] 的伤害构成

`血染·蜕变`：「子弹造成伤害时，**消耗 1 层[羽化]**，对目标额外造成 **500% 灾厄伤害**，视为远程武器伤害」
＋ `织羽·剥茧`：「[羽化] 效果的伤害倍率**额外附加自身最大生命值 80% 的灾厄伤害**」
⇒ **单层[羽化] = 500% 灾厄伤害 + 80% 最大生命**（两段，且都带 `充盈` 标签）。

⚠️ **标签决定吃哪套面板**：`技能字段` 里这两条的 tag 是 `["远程","武器","充盈"]`
⇒ 走**武器伤害**结算，**整体再 × (1 + 充盈威力)**。讲「为什么羽化这么痛」时把三重口径说全：
武器伤害 + 充盈标签 + 最大生命附加。

### 推导链 4 · 倍率的等级口径（读到数组别直接报）

`技能字段` 里数组型倍率是**逐级成长**的，**右端 = 满级（12 级）值**，不是当前值。

- 例：`坠入黑渊` 的 `充盈伤害 = [0.16 … 0.49]` ⇒ 满级是 **49% 最大生命**，1 级是 16%。
- 例：`浴血` 的 `伤害 = 6.6`（固定值，不吃等级）＋ `治疗 = 0.5`（回 50% 生命）。

⚠️ 引用时**必须说明给的是满级还是 1 级值**；角色技能的倍率先升后降时工具会写成 `55% → 187%（技能等级 1 → 12）`，右端为满级。

### 口径换算 · 溯源会改写「间隔 / 频率」类数字

角色的 `溯源` 数组第 1 条 = 1 溯。**基础描述里的「每隔 N 秒」通常是 0 溯口径。**

法露茜实证：`技能术语解释` 的 [执行者] 写「**每隔 3 秒**转化攻击力」，而 **1 溯原文** = 「转化攻击力**间隔降低 50%**」
⇒ **实际 1.5 秒**。构筑常带 4 溯 / 6 溯，此时 1 溯必然在内。

⇒ **引用任何「间隔 / 频率」类数字前，先读 `溯源` 看有没有修正项**，并标明是 0 溯还是实际口径。
直接照抄术语解释里的 3 秒，是最典型的错答。
（1 / 4 / 6 溯是机制型 —— 改间隔 / 加成状态 / 给穿透；2 / 3 / 5 溯是数值型 —— 加强化战技 / 抬技能等级。）

### 口径换算 · 强化战技的层数

`觉醒` 技能字段给出两个**别混用**的数：`[觉醒值]最高不超过 100000`（**上限**）、
**`消耗[觉醒值]阈值 = 15000`**（释放 [暗影奔袭] 时消耗 [觉醒值] 提升倍率；达阈值按强化口径）。
问「什么时候变强化版」答**阈值 15000**，问「最多攒多少」答**上限 100000**。

## 手法

- **对单 / 共斗**（社区口径）：每个新 BOSS **先按终结技**上 [处决目标] → **近战普攻穿插重击**叠 [火属性紊乱] 层数与 [觉醒值] → 当 [觉醒值] ≥ **15000**（对应上文「口径换算 · 强化战技的层数」的「消耗阈值」）且目标紊乱 ≥ **3 层**时，**释放战技**结算紊乱伤害，循环。
- 层数图标（社区口径）：3 层 [火属性紊乱] = 半圆图标，6 层 = 整圆图标。
- **低溯源叠满再放战技**输出最大化；**6 溯叠到一半即可穿插**技能。
- 联袂模式换 BOSS 会**断标记**（出现放战技却不消耗紊乱层数的情况），**重新按终结技**即可。
- ⚠️ 177xz 口径「配鞭刃打近战群怪、切双枪打远程爆发」——数据包法露茜精通是**双刀 / 双枪**，并不精通鞭刃，此条属社区泛述，具体以 `read_entry char 3104` 为准。

## 已知疑点 / 优劣

- **优劣**：对单 / 共斗强度高；**对群乏力**——社区口径「[处决目标] 至多为 5 个，所以对群略显乏力」。最有辨识度的处决循环需玩家亲自控制，主控位更能兑现对单强度。
