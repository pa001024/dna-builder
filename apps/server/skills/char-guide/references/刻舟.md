# 刻舟（仗剑游）

> 数据包内名 **刻舟**，`char id 1503`（属性 / 标签 / 精通 / 专武 / 溯源原文都在 `read_entry char 1503` 里，本文件不重复原文）。数据包 `标签` = 输出 / 武器伤害，`精通` = **全部类型**，`专武` = **20510「若华的飞光」**（突击枪）。

## 一句话定位

光属性**武器输出**角色，机制特殊：**直接用远程武器叠「剑意 / 弦意」，再用终结技切近战 [剑非剑] 形态收割**。社区口径「**刻舟本身倍率不算优秀，但他能吃到别人吃不到的一批武器向 BUFF，满配下伤害不低于赛琪这种技能威力型同律武器大 C**」。**只适合手操主控，AI 用不了**（见下）。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通 = 全部类型**，天然满足门槛，可直接套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **两段循环**：常态用**远程武器**输出，把 [剑意值] 转化为 [弦意值]；满值时放**终结技 [霜剑拂流星]**，切出近战 **[剑非剑]**（可切**单手剑 / 长柄 / 重剑 / 双刀**多种模式）打一套，[犹记刻舟痕] 结束再放终结技回常态。
- ⚠️ **[剑非剑] 继承近战武器面板**：基础面板、攻击类型、暴击 / 爆伤、攻速、触发概率、攻击范围，以及**魔之楔带来的攻速 / 暴击 / 爆伤 / 攻击 / 触发 / 连击补正等词条**都能继承；但**武器自带的被动 / 招式特效（如蒙恩御礼的蓄力暴伤）不生效** ⇒ 所以**近战武器看基础面板（双爆）而非特效**。
- **战技 [少年游]**：常态提远程攻速 / 触发概率；[霜剑拂流星] 期间提近战攻速 / 触发概率。
- **被动 [浮生多变化]**：剑 / 弦意收益倍率 —— 社区提醒「**刻舟被动给大量造成伤害提升（10 级 + 1 溯时 100 剑意值 ≈ 250%）**，与决斗 / 陷阵同级」。
- **操作手法（社区口径）**：`战技 → 远程武器普攻到左侧 [剑意值] 满 → 终结技 → 普攻到右侧 [弦意值] 满 → 终结技 → 再战技`，循环。⚠️ **尽量在满值时放终结技**（能大幅减少终结技消耗）。

## 技能升级优先级

- **社区口径**：**所有技能都建议拉满** —— 小技能决定攻速上限，终结技直接影响 [剑非剑] 普攻输出，被动提高伤害倍率与触发概率，额外被动给攻击力 / 武器暴击率 / 团队攻击加成。
- **社区口径**：**终结技 [霜剑拂流星] > 被动 [浮生多变化] > 战技 [少年游]**。
- ⇒ 两口径不冲突：资源够就全满，紧则先终结技 / 被动。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：[浮生多变化] 每点收益倍率 +0.7%；**20 米内仅有 1/2 名敌人时，每次武器伤害转化 3/2 点** —— 社区口径「**加快循环 / 对单手感显著提升**」。
- **2 溯（毕业门槛 / 必带）**：造成伤害触发额外效果时获得**造成伤害 +90%（5 秒）并回复 2 点神智**（回复 CD 约 1 秒）—— 社区一致口径：**刻舟输出高度依赖终结技衔接、神智压力大，2 溯是「能不能顺畅循环」的关键**。社区补充：**队伍没扶疏时明显减轻回能压力**。
- **4 溯**：放终结技后获得 **[风拂月照]**（受击不僵直 + 减伤 25%，25 秒）—— 社区口径「**不加伤害但大幅提高舒适度，避免连段被打断**」。
- **6 溯**：造成伤害触发额外效果时叠 **属性穿透 +3%/层，最多 18 层**（约 +54%）—— 靠**高频远程攻击快速叠满**，再切近战爆发，**对高防敌人提升明显**。
- ⇒ 结论口径：**1 溯加快循环、2 溯必带、4 溯保舒适度、6 溯拉穿透上限**（多方一致）。

## 队友

- 线上队友组合基本就是 `菲娜 + 松露与榛子`，另有几份未填队友。
- 机制上菲娜给的**攻击力 + 穿透 + 追击**能完整承接刻舟的武器伤害输出，是核心增伤位；`松露与榛子`补治疗 / 增伤与 2 溯增益。
- ⚠️ 旧稿称「刻舟 + 扶疏 + 菲娜 = 伤害最大化」，但线上 **没有一份带扶疏** —— 以线上为准。
- ⚠️ **刻舟只适合主控**：AI 操控时只能用单一武器，而他需要在远程 / 近战之间频繁切换 ⇒ 交给 AI 无法发挥（机制结论，与配装无关）。

## 已知疑点（社区未定论，不要当结论讲）

- **精通口径**：数据包是 **`精通` = 全部类型**；部分讨论写作「**近战全精通 / 远程仅突击枪**」，与数据包略有出入 —— 回答时**以数据包为准**，社区说法标「社区口径」。
- **近战武器排序**：鎏金岁月 / 红叶一滴 / 春玦戟 / 追忆的残影 各有拥趸，差异来自「双爆面板 + 架势 + 获取难度 + 熔炼」，**没有唯一解**，按持有取舍。
- **技能耐久阈值**（约 241%）随魔之楔等级变动；**流光交辉吃满**的具体数值以游戏内面板为准。
- **对空能力弱**是公认短板（追忆的残影靠继承的攻击范围部分弥补）。
