# 魔灵 · 潜质 · 你好箱点位

> 结论先行：**前期只做三件事**——① 做支线「魔灵啊魔灵」解锁魔灵；② 拿下 2 个 **100% 你好箱**一次性点位；③ 主用 **[你好箱]**（奇迹/锐意/闪亮任一），副槽带 **[巧手]**（支线「我可以养它吗？」送，一键解锁副本机关）。
> 刷本收益分 **【委托报酬】与【掉落拾取】**：委托报酬通关即得，掉落拾取需击败敌人并拾取掉落物，因此「拾取范围 + 额外掉落」的你好箱为日常刷本首选。

## 一、魔灵系统

- **解锁**：支线 **「魔灵啊魔灵」（夜航篇第一章 黑铁·白花）**。成年/开局要点里另有 **「我可以养它吗？」** 送 **[巧手]**。
- **两类**：
  - **活力魔灵**：可作伙伴上场，有**潜质槽位**，槽位随**星级突破**逐步解锁。
  - **失活魔灵**：有潜质但**不能上场**，只能当素材——通过**【魔灵训练】**让活力魔灵学会失活魔灵的潜质，通过**【升阶】**提升已学潜质的等级。
- **升级 / 突破**：吃 **妙妙膏膏** 升到当前阶段等级上限，然后消耗素材突破，**一般是消耗同类型魔灵**。
- **类型（活力魔灵）**：**【奇迹】/【锐意】/【闪亮】**。三者**除了「闪亮」初始多一个潜质槽位之外没有差异**，也都可以当突破素材——别以为哪个类型更"高级"。
- **潜质等级**：**蓝 → 紫 → 金**（低到高）。

## 二、你好箱（日常刷本首选魔灵）

被动：**拾取范围增加 + 击倒敌人获得的经验增加 + 概率获得额外掉落**（数据核对 `read_entry pet 奇迹你好箱` 的**被动**字段，三级数值逐档提升）。
主动：对周围敌人造成伤害，**探测 100 米内 1 个魔灵和 1 个储物箱**，30 秒内持续标记位置——找宝箱/找魔灵都靠它。

### 提高投喂成功率

- 【铸造】→【材料】→【消耗材料】可铸造 **【妙妙妙罐罐】**，投喂时使用**提升成功概率**。
- 另有一条概率来源：**【历练】→【委托】→【委托】中的「委托事件」**——其中**【解救魔灵】事件有概率出现你好箱**：
  - 【探险/无尽】+【勘察/无尽】**每周共 30 次**可触发【解救魔灵】；
  - 【驱逐】+【追缉】**每周共 20 次**可触发。
  - ⇒ 刷委托时顺手触发，等于每周白送 50 次摸奖。

## 三、常见提问落点

| 提问 | 答法 |
|---|---|
| 你好箱在哪 | 先给 2 个 100% 一次性点位（下水道 / 龙莎要塞缺口），再给刷新点位表；坐标查不到要说清楚 |
| 你好箱多久刷新 | 区域 3 天 1 轮；投喂失败次日 05:00 同位置重刷 |
| 投喂老失败 | 铸造【妙妙妙罐罐】提高成功率；或等次日刷新；或刷委托触发【解救魔灵】事件 |
| 魔灵怎么突破 | 妙妙膏膏升到当前阶段上限 → 消耗同类型魔灵突破 → 解锁下一个潜质槽位 |
| 闪亮比奇迹强吗 | 只有「初始多一个潜质槽位」的差别，其余无差异，都能当突破素材 |
| 失活魔灵有什么用 | 当素材：魔灵训练给活力魔灵学潜质、升阶提升潜质等级（蓝→紫→金） |
