# 狩月账本（AFK Ledger）

> 把「小小狩月人」奖励管道的原始事件，整理成可查、可统计、可常驻桌面的产出记录。
> 本文是产品与数据口径说明；实现见 `apps/web/src/utils/afk-ledger.ts`、`apps/web/src/store/afkLedger.ts`、
> `apps/web/src/views/AfkLedgerView.vue`、`apps/web/src/components/AfkLedgerChart.vue`。
> 入口：More → 狩月账本（仅桌面端；路由 `/afk`）。

## 1. 定位

| 项 | 结论 |
| --- | --- |
| 用户 | 长时间挂机委托、想知道「这一轮到底刷出了什么」的 PC 玩家 |
| 核心问题 | 官方浮窗只有流水，没有按场次、按副本、按天的产出账 |
| 解法 | 本地 Dexie 持久化 + 一页可筛选的账本 + 一条可自定义的屏幕信息条 |
| 不做 | 不做市场价/金币估值（没有可靠价格源）；不做云端同步；不替官方工具 |

## 2. 数据口径

| 概念 | 定义 |
| --- | --- |
| 场次 run | `enter` 建场并写 `status="running"`，`complete` 收尾改 `status="done"`。只有开始帧的场次一直显示「进行中」，时长列不写 00:00；重开应用时最近 6 小时内未结束的场次恢复为进行中，更早的才按完成收尾（兜底） |
| 掉落 drop | `reward` / `craft` 事件，数量按 `count` 累加；`rarity>=5` 记为金色 |
| 铸造产物 | `craft` 与副本无关，`runId` 恒为 null，不进副本产出/趋势/品质/排行，页面上是独立统计卡片 |
| 迷津 | 管道用 `id=20`、占位名「测试场景」下发，账本与事件摘要统一显示为「迷津」，链接到 `/db/rouge`（`AFK_DUNGEON_ALIASES`） |
| 归属 | `reward` 到达时若有进行中的场次就直接归它；没有才挂起（`runId=null`），由下一次 `complete` 整批认领，作为错过开始帧的兜底 |
| 去重 | 同一条 `complete` 会在瞬间重复多次，按「副本 + 3 秒」去重，不能重复计场次 |
| 本次 session | 当前这一次管道连接（游戏重连或应用重启会开新 session） |
| 今日 | 本地时区 00:00 起 |
| 回放 | 连接瞬间补发的历史事件**不写库**，只显示在事件流；账本从开启同步后开始记 |
| 保留 | 90 天，超出在初始化时清理 |
| 备份 | 导出 `{ version, exportedAt, runs, drops }` 的 JSON；导入按自然键（场次=副本+起止+状态，掉落=类型+物品+时刻+数量+场次）去重合并，只增不改，`runId` 会重映射到本地场次 |

> 「收益」在本页指掉落产出（件数、金色件数、场均、每小时），不是货币价值。

## 2.1 品质表示

事件里的 `rarity` 是 `1..5`，对应 **白 / 绿 / 蓝 / 紫 / 金**。页面遵循仓库既有的「只用颜色表示品质」约定：

- 名称（白/绿/蓝/紫/金）**只出现在筛选栏**；
- 物品排行、品质分布、事件列表一律用色块（`utils/rarity-utils.ts` 的 `getRaritySwatchClass` / `getRarityColor`）；
- 任何位置都不出现数字品质。

## 3. 页面结构

```
┌ 狩月账本 ────────────────────────────────────────────────┐
│ 挂机委托与掉落的本地记录          [今天][7天][30天][全部] │
│ [副本: 全部 ▾] [品质: 全部 ▾]                    [清空] │
├──────────────────────────────────────────────────────────┤
│ 完成场次 │ 总掉落 │ 金色掉落 │ 场均掉落 │ 累计时长       │
├───────────────────────────────┬──────────────────────────┤
│ 掉落趋势（柱=件数 线=金色）   │ 品质分布（颜色堆叠条）   │
├───────────────────────────────┼──────────────────────────┤
│ 物品排行（名称/品质/数量/占比）│ 副本产出（场次/件数/场均）│
├───────────────────────────────┴──────────────────────────┤
│ 最近场次（时间 / 副本 / 时长 / 掉落 / 金色 / 状态）      │
└──────────────────────────────────────────────────────────┘
```

- 空状态：一句「还没有记录」+ 去设置页开启「小小狩月人同步」的入口。
- 筛选只影响页面，不影响已经持久化的数据。
- 清空需要二次确认。

## 4. 屏幕信息条条目

新增条目类型「狩月账本」，三个维度：

| 配置 | 取值 |
| --- | --- |
| 指标 | 完成场次 / 掉落数量 / 金色掉落 |
| 范围 | 今日 / 本次 |
| 来源 | 全部副本 / 某个已记录副本 |

渲染成一颗胶囊：`[图标] 扼守/无尽 今日 3 场`。数据由主窗口写入
`localStorage["dna.afkLedger"]` 快照，浮窗每秒读一次，不直接打开 Dexie。

## 5. 与官方工具的关系

接收端与官方工具二选一（同一个管道名）。账本只消费本应用接收到的实时事件；
官方工具关闭后，进入/退出挂机场景即可让游戏连到本应用。
