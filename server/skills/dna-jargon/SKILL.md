# 二重螺旋 社区黑话对照

玩家社区大量沿用 Warframe 的术语体系，再叠加对角色 / 武器外形与技能梗的戏称。
本表把这些**非官方叫法**对应到**游戏内官方名称**，供检索与理解提问时统一口径。

官方名带**站内链接**（形如 `[贝蕾妮卡](/db/char/1101)`），路径与 `query_module_entries` 返回的 `path` 同源。
回答里可**原样取用**；但**不要凭空编造**表里没有的 id —— 要新链接就用检索工具拿 `path`，别自己拼。

## 使用方式

1. 用户提问先做一次**称呼归一化**：把黑话替换成官方名再检索 / 计算，避免拿黑话去撞库。
2. 回答时通常**第一次出现给官方名**（「技能效益（俗称效率）」），之后可用简称。
3. 黑话**不是官方文案**，不要把它当成游戏里的显示名原样输出给用户之外的场合。
4. 遇到**指向不唯一**的黑话（见文末「注意」）要先反问确认，不要自行择一。

### 同律武器（俗称「显赫 / 显赫武器」）

- 官方名 **同律武器**。当前数据中含同律武器的角色为 **[贝蕾妮卡](/db/char/1101)、[莉兹贝尔](/db/char/1501)、[琳恩](/db/char/3101)、[赛琪](/db/char/5301)**（以数据包 `同律武器` 字段为准）。
- 有**专属魔之楔槽位**与专属魔之楔；角色养成界面可切换到同律武器栏位。
- 倍率显示在**技能面板**，因此**吃技能威力**的倍率加成；但打出的伤害是**武器伤害**，**不吃技能伤害加成**。
- 该外号来自 Warframe 的 Exalted Weapon（显赫武器）。

### 极化（调整槽位趋向）机制

- 每个魔之楔有「**耐受**」消耗值，角色本体的**耐受上限**固定：
  `耐受上限 = 20 + 角色/武器等级 + 中枢位羽蛇的「最大耐受」`（羽蛇金件「最大耐受」实测为 17）。
- 通过**[移转模块](/db/resource/201)**把槽位趋向调整为与某个魔之楔**极性相同**（极性有 `A / D / O / V` 四种），
  对应魔之楔放进该槽位后**耐受消耗减半**，从而装上更多魔之楔。
- 极性不匹配会**加重消耗**（惩罚），所以极化方向要跟着配装走。

## 注意

- **「专属」指向不唯一**：用户只说「专属」时先问是哪个（或多个属性各自的专属）。
- **词源含猜测成分**：如「豆子」的由来、「深渊」一词的确切出处，社区多为推测，**不要当作考据结论输出**。
- **同名不同物**：`羽翼·鼓舞` 这个名字在**海妖**（金 / 蓝）与**牧神**（紫）系列中均存在，
  玩家口中的「金效率 / 鼓舞」默认指**金色[海妖之羽翼·鼓舞](/db/mod/51301)**，遇到歧义要确认品质。
- **数据以游戏内为准**：本表数值（耐受上限公式、具体魔之楔加成）来自当前数据包快照，
  版本更新后可能变化，涉及精确数值时建议回到游戏内或最新数据核对。
- **链接口径**：详情链接 `/db/<模块>/<id>` 的 id 取自当前数据包实测；若失效（版本迭代改名 / 换 id），
  以资料库站内检索为准，**不要用旧 id 猜新条目**。
- **魔之楔列表页的系列筛选参数是 `ser`（不是 `series`）**：`/db/mod?ser=百首`，值用**中文系列原名**。
  同一页面其它筛选参数的短名：`tp` 类型 / `ql` 品质 / `el` 属性 / `ver` 版本 / `id` 选中条目。
