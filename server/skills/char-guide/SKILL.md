# 二重螺旋 · 角色攻略索引

> **本技能是什么**：一份**按角色分文件**的攻略索引。数据包（`read_entry` / `query_module_entries`）给的是技能原文、魔之楔效果、溯源文字这些**散点事实**；玩家真正会问的是「**这个角色到底怎么练、怎么打、和谁组队**」——那是数据包里**没有**的结论，本技能就是补这一段。
>
> **配装怎么来的**：**取自 dna-builder 站上真实的玩家分享构筑**（抓取于 2026-10-06，带站内链接），**不是推测**。机制与手法部分为社区口径。
>
> **本技能不是什么**：不提供 DPS 数值、不给强度排名、不复述技能描述（那些用 `read_entry` 读原文即可）。
>
> ⚠️ 机制 / 手法部分为**社区口径**，成稿于 **2026-10**、环境大致为 **1.5–1.6 版本**；**配装结论会随版本失效**，引用时必须带时效。

## 怎么用

1. **先在本页「角色索引」定位角色**，再读对应的 `references/<角色名>.md`（正文用 `read_file` / `grep` 按路径取）。
2. **配装问题先看文件里的「配装」节**——它来自 dna-builder 站上**真实玩家上传的构筑快照**，不是推测。有推荐构筑的角色，该节以**推荐构筑的完整配置为基准**；没有的为定性汇总。每份构筑都带**站内链接**，可直接给用户；回答时可以照着念那份链接里的配置。
3. 文件里的**魔之楔名 / 武器名**要回数据包复核（`read_entry` 的 char / weapon / mod 条目，或 `query_module_entries`）。市面文章**串稿与编造很常见**——各文件已把已知的错误写法标成「不采信」，别把标了不采信的名字输出给用户。
4. **社区结论 ≠ 数据包事实**。回答时分开说：机制 / 字段回数据包，配装以文件里的**线上构筑**为实证、标「线上构筑口径」。
5. 要算具体收益（换件差多少）→ 配装侧实算；本技能只给**线上构筑的现状**与字段落点。

## 配装口径：以线上构筑为准（重要）

本技能的「配装」一律取自 **dna-builder 站上玩家上传的完整构筑快照**（`charSettings` 全量：武器 / 中枢 / 四类魔之楔 / 魔灵潜质 / 队友 / BUFF），**不写凭空推测的配装**。

- **抓取时间**：**2026-10-06**。每个角色文件里都写了该角色当时的构筑份数。
- **站内链接**：形如 `https://dna-builder.cn/char/<charId>/<buildId>`。文件里列出的构筑都带链接，**可以直接给用户**。
- **呈现方式**：**有推荐构筑（标 ★）的角色，配装节直接给出该份的完整配置**（武器 / 中枢 / 四类魔之楔 / 魔灵潜质 / 队友 / 口径），其他构筑列后作参考，节名「以推荐构筑为准」；**没有推荐构筑的角色为定性汇总**（主流 / 常见 / 偶见），节名「以线上构筑为准」——**两类都不写逐项出现份数**。
- **AI 构筑的武器位**：标题带「AI / 挂机」的构筑，角色实际只带一把武器，另一把是**占位符**（如止流挂机件里的 `归墟棘轮`）——读配装时别把占位武器当成实际用法。
- **时间一律用「更新于」**（即 `updateAt`，作者最后一次改这份构筑的时间），**不要用创建时间**——一份 6 月建的构筑可能 9 月才更新，用创建时间会把它当成过时货。
- **口径必须一并读**：作者算 DPS 用的敌人（id / 等级 / 抗性，`-4` 表示属克）、和鸣档位、角色与技能等级都写在文件里。**不同口径的数字不能横向直比**，转述数值时必须带上口径。
- **0 份构筑的角色**：文件里明确写「线上 0 份分享构筑」⇒ **没有可参考的线上配装**，此时只能说机制上确定的部分（精通武器类型、定位），**不要补配装**。
- ⚠️ 线上构筑是**玩家自算**，可能过时、可能有误（作者自己的「自定义变量」只是替代式）；它是**水平的实证**而不是权威。转述时说清「这是站上某份构筑的配置」。

## 近战连击机制（连击点数 / 连击等级）

**每次近战非蓄力攻击（普攻 / 下落 / 滑行）命中即获得连击点数，命中多个目标可重复计点**；该获取可被 `幸运` 系近战 MOD 加成（`幸运·领界` 52204 / `幸运` 32202，满级效果「通过攻击获得连击点数时，有 100.0% 概率额外获得 1 点」）。点数抬升**连击等级**（低→高；社区记法 D/C/A/B/S，也常省略 D 写成 C-B-A-S）。**蓄力攻击消耗连击点数**（棘刺绝响 `灾厄熔炼` Lv.3 原文「每累计消耗 120.0 点连击点数」），等级越高蓄力伤害越高；连击等级同时是部分 MOD / 武器特效的变量（`时运` 的触发概率、`红叶一滴` 的 ×连击等级）。蓄力加成倍率是**配装侧建模 BUFF**（D/C/A/B/S = 0/100%/300%/400%/700% 独立乘区，`read_entry` 读不到、别当数据包事实），详见 [棘刺绝响](references/棘刺绝响.md)。

**返还 / 补给类机制都有「启动过程」**：连击点要先攒起来、等级要先爬上去，返还循环才转得动——莉兹贝尔 7 溯（消耗的连击点返还 90%）、棘刺绝响 5 熔（连击溢出转 [厄运之痕] 补进蓄力）都是如此。具体启动手段属**角色专属打法**（怎么攒点、用什么武器启动，由各角色技能决定），见对应 `references/<角色名>.md`，不在本节展开。

## 名字口径（先读，最容易答错）

- **伊薇 = 「艾达（？？）」**。`char id 2102`，内部 icon `Eve`。**1.5「乐园序曲」上线时对外写作「艾达（？？）」，1.6 起改用真名「伊薇」**；社区攻略、旧公告、图片攻略里**仍大量写「艾达」**。⇒ 用户说「艾达」时**不要回答“资料库没有这个角色”**，直接按伊薇处理。
- **主角三形态**：数据包拆成 `主角-暗(1201) / 主角-光(1601) / 主角-水(2201)`，社区叫「暗主 / 光主 / 水主」。用户只说「主角 / 狩月人」时**先问属性**，三种形态定位完全不同（暗=输出、光与水=辅助）。
- 其余社区外号（女枪 / 蝶妹 / 水母 / 猪妹 / 老板娘 / 椅子男 / 栗子 …）见 `dna-jargon` 技能。

## 时效口径

- **线上构筑一律按「更新于」（`updateAt`）算新旧**，不用创建时间——一份 6 月建、9 月改过的构筑是**新的**。文件里已经写的是「更新于」。
- 机制 / 手法部分为社区口径，**越靠后的版本资料越准**；1.0–1.2 时期的老攻略（尤其涉及魔之楔名与「背水 / 昂扬」取舍的）经常已被推翻。用户拿一篇具体攻略来问时，**先判断它属于哪个版本环境**再决定沿用还是校正。
- **第七根源（第 7 溯源）**：数据包 `溯源` 与 `第七溯源消耗` 已收录（贝蕾妮卡 / 卡米拉 / 莉兹贝尔等），但开 7 溯的**材料来源与限时兑换**属运营信息，会过期，不要复述成现状。
- 福利 / 活动 / 商店轮换（「邮件送 50 个」「XX 进商店了」）**会过期**，不要复述成现状；这类运营信息不在数据包里。
- 涉及「现在哪个强 / 该练谁」时：**给方向与适用场景，不给裸排名**（强度随版本与敌方环境变）。

## 未收录 / 边界

- **`SP黎瑟`(4103)、`莉莉蔻`(5402)**：数据包里条目存在但**技能字段为空**（未上线 / 未放数据），也没有可信攻略 ⇒ **如实说查不到**，不要拿同属性的其他角色顶替。
- 数据包角色版本到 **2.0**；线上构筑快照抓取于 **2026-10-06**，机制资料集中在 **1.5–1.6 版本环境**。
- **三个角色线上 0 份构筑**（玛尔洁 / 兰迪 / 西比尔）：这些角色**没有线上配装可参考**，文件里已写明，不要用别的角色或推测来补。
- 兑换码、限时活动、掉落表这些**运营信息**不在本技能范围，别编。

## 边界与诚实

- 不提供 DPS 数值与强度榜；**配装以文件里的线上构筑实况为准**（玩家自算，可能过时或有误，不是权威）。
- 市面文章**串稿与 AI 编造很常见**（魔之楔名对不上数据包、把别的角色的专武写串）。各文件已把这类写法标注为「不采信」——回答时**只输出核对过的名字**。
- **查不到就说查不到**：线上 0 份构筑的角色就说「线上没有配装可参考」；没有资料的落点在各文件里明确写「未找到可信近期资料」，不要补齐式编造。
