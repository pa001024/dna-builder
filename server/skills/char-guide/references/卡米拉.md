# 卡米拉（赤影佳酿）

> 数据包内名 **卡米拉**，`char id 3202`（属性 / 标签 / 精通 / 专武都在 `read_entry char 3202` 里，本文件不重复原文）。`专武` = 远程·突击枪 **「杯中的残火」**（`read_entry weapon 20512`）。
> 版本：1.3 实装。数据包 `标签` = 输出 / 技能伤害 / 辅助。
> 本文件为**社区口径汇总**，配装结论**只作方向参考**，条目名随版本变动，引用前建议 `read_entry` 复核。

## 一句话定位

火属性**技能输出 / AI 协战副 C**，社区俗称「老板娘」。用终结技「赤霞珠舞」召唤环绕的 [开酒刀]，长按战技「猩红欢宴」击飞开酒刀挂 Dot [酒红伤]，靠**移除 Dot 的伤害**出伤。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- 核心耦合：**卡米拉自己挂 Dot（开酒刀）、自己耗 Dot，无法两头兼顾** ⇒ 社区一致口径「**必须配一个高频火属性伤害的队友**去触发 [酒红伤] 移除」。
- **社区口径**：卡米拉定位≈「火队里的煜明」，**AI 表现非常稳定**，适合放协战位补伤害；但 1.3 时点「没有频率够高的火系队友（女枪都不行）」，处于**冷板凳**，等 1.4 女仆（希尔妲）搭配。
- **属性堆叠（社区口径）**：**技能范围只影响战技本身、不影响主要伤害源 [开酒刀] 的范围，无需高堆**；**技能耐久影响 [开酒刀] 持续时间，但放战技时 [开酒刀] 计时暂停，也不用堆** ⇒ 能堆的只有 **技能威力与技能效益**。

## 技能升级优先级

- **社区口径**：**被动建议满级，终结技、战技 8 级或满级**。
- **社区口径**：**被动优先 > 终结技 > 小技能**（被动直接提 [酒红伤] 额外伤害倍率；战技最后升）。

## 溯源取舍

- 数据包 1–7 溯逐条见 `read_entry char 3202`（含 7 溯）。社区关键节点：
  - **1 溯**：开酒刀伤害 30% 概率额外叠 1 层 [酒红伤]。

- **社区口径（1.3 时点）**：称「**7 命是官方钦定弱者认证**」的调侃，「能玩但别想多强」⇒ 属**当时口径**；1.6 后 7 溯卡米拉作为法露茜优质队友被重新启用（见下）。

## 队友

- 线上队友**最多的是「不带队友」**（推荐构筑带 `扶疏 + 法露茜`）；带队友的零散为 `松露与榛子 + 希尔妲`、`扶疏 + 菲娜`、`希尔妲 + 菲娜`、`菲娜 + 法露茜`，另有单 `扶疏`。
- 机制上卡米拉「自己挂 Dot、自己耗 Dot」，**必须配一个高频火属性伤害 / 属克的队友**才能兑现 [酒红伤] 移除伤害——线上带队友的样本正是 `法露茜`、`希尔妲` 这类火属性队友，方向与机制一致；线上多数样本为单算卡米拉本体而留空队友，并未否定这条机制。

## 已知疑点

- **协战武器归类一致**：社区均指向「杯中的残火」，与数据包专武一致。
- **1.3 vs 1.6 定位翻转**：社区（1.3）判「冷板凳 / 未来可期」，1.6 后 7 溯卡米拉被用作法露茜队友 ⇒ **引用时标注时点**，不要拿 1.3 的结论回答 1.6 的问题。
- **7 溯强度**：原作者原话「七命后能玩，具体多强别想」——属**玩家主观口径**，非数值结论。
