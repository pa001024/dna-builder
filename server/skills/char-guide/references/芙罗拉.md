# 芙罗拉（反逆花序）

> 数据包内名 **芙罗拉**，`char id 1102`，`专武 10107`（「囚鸟的刺羽」，近战单手剑）。技能 / 标签 / 精通 / 溯源原文都在 `read_entry char 1102` 里，本文件不重复原文。

## 一句话定位

暗属性**武器输出**，单手剑（近战）特化；核心是**开终结技铺领域**，靠战技 / 普攻攒层 → 转层 → 强化蓄力打爆发。她是典型的**灾厄武器承载者**（大后期靠灾厄突击枪拉上限），社区定位为「终极 6 溯战士」——6 溯前注意点很多、6 溯后质变。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- 循环骨架：**开终结技 → 领域自动攻击 → 近战普攻 / 战技攒 [重奏] → 转 [花刺] → 强化蓄力（[终章]）爆发**。
- **她的技能「视为近战武器伤害」**——社区反复强调三点：① 伤害同时计入**角色攻击力与武器攻击力**（所以堆武器攻击力能放大技能伤害）；② 能吃双暴乘区（暴击后伤害远超不暴击）；③ 属性克制乘区对武器面板的收益有限（社区实测只 +10%~20%）。⇒ 这条决定了「**堆攻击力 / 双暴**」而不是只堆技能侧。
- 社区另有一句口径：**她所有技能都不吃「技能威力」加成**，唯一例外是**终结技给的暴伤**吃技能威力（满练度下 1% 技能威力 ≈ 0.08% 总伤）。
- 战技 [小步]/[跃步] 与 [交响] 层、[重奏]、[花刺] 是她的资源条，具体定义看 `read_entry char 1102`。

## 技能升级优先级

社区口径：**战技先到 8 级，终结技与被动尽量拉满**；资源不足时先全体点 8 级过渡。

## 溯源取舍

- **1 溯**：优化手感 —— 单次战技 [交响] 由 10 层提到 15 层（两次即可叠满 30），消耗 [交响] 时回赠 1 层 [重奏]；且持有 [交响] 时**近战暴击率 +75%**。⇒ 社区把它当作**降低「必暴」门槛**的关键档（专武需要高暴击）。
- **2 溯**：近战暴击给 [重奏] 由 1 层提到 2 层；每 6 层 [重奏]，[圆舞] 间隔最多缩短到 0.5 秒 —— 主打小技能 / 挂机流的提升约「一半」。
- **4 溯**：**回神智由 1 点提到 3 点** + 消耗 [交响]/[重奏] 额外给连击点数 —— 社区称「4 溯后神智循环基本自转」，**对扶疏的依赖明显下降**。
- **6 溯**：终结技领域期间**全属性穿透 +30%**；[终章] 时 [花刺] 不足 12 层可消耗 [重奏] 补满；[终章] 后追加 5 次 [圆舞]。⇒ 社区口径：**「每一发 [终章] 都是最高倍率」**。
- ⇒ 结论口径：**1 溯降门槛、2 / 4 / 6 溯是机制级强化**；只求能用先解锁 2 溯（沉浸式戏剧打完即可取），要**解放扶疏基本要 4 溯**。

## 已知疑点（社区未定论 / 易错点）

- **「花刺层数加伤」历史 bug**：社区口径称该 bug **已修复**——修复后**特殊蓄力必须在满 [花刺] 层时释放**，之前版本「满不满没区别」的旧结论已失效。
- **必暴门槛**：专武 + 魔之楔堆出来的暴击率可能**溢出 100%**，可把紫色 专注 换 **透析**，但会有「等虚妄献祭叠满」的空窗期；具体怎么取舍社区无定论。
- **灾厄武器昂贵**：没成型的棘刺绝响前，用侧重面板的远程（剥离 / 爆破艺术）或范围 / 耐久类过渡。
- 不实文章给的「技能威力百分比」「攻击力翻十倍」等数字多为推论或过期，**不要当结论报数**。
