## 一句话定位

暗属性**同律武器 / 武器输出**，精通 **单手剑 · 双枪**，开局赠送 + 密函最早开放，是门槛最低的毕业位之一。
开 7 溯后定位从「平滑输出」变成**「紊乱联动的爆发位」**：输出重心压到 **[伊弥尔] 第五段剑气**触发的那一次追加伤害上，实战强度取决于 **[暗属性紊乱] 的覆盖率**与**第五段剑气的命中频率**。

## 机制读法（7 溯版）

**底子（1.0 起就没变）**

- 终结技 [冥焰] 把她切进**同律武器 [伊弥尔]**：独立魔之楔系统（换武器后普通武器魔之楔失效）、普攻变成剑气、受击不僵直、禁用下落攻击，同时**每秒烧 30 点神智**（神智归零或再按一次收回）。
  ⇒ 所以「**技能效益 / 最大神智 / 回神智**」是她的续命主线，也是唯一不能省的一条。
- [伊弥尔] 的普攻是**一段～五段剑气**（倍率逐段抬高，第 5 段最高），全部按 `技能威力` 结算、tag 属「近战 / 武器 / 普攻 / 同律」。
- 战技 [残光] 无 CD、可空中放、可插连招，兼位移 + 聚怪 + 4 次暗属性范围伤害 ⇒ 也是赶路手段。
- 被动 [回转]：[残光] 与单手剑伤害**有概率回神智** ⇒ 这条决定了她**强绑单手剑**。
- 被动 [余火]：放完 [冥焰] 后下一次 [残光]**不耗神智** ⇒ 标准的「开大 → 白嫖一次 [残光]」。

**7 溯带来的三段式（本文件的核心）**

[伊弥尔] **第五段剑气**造成伤害时：

1. **消耗目标 3 层 [暗属性紊乱]**；
2. 追加 **1 次 1500% 暗属性充盈伤害**，并**视为同律武器伤害**；
3. 成功消耗 ⇒ 自身叠 **1 层 [燎原]**（10 秒、最多 5 层、叠层刷新剩余时间）。

**[燎原] 每层**：全属性穿透 **+10%** / 技能威力 **+25%** / 武器攻击速度 **+15%** / 武器触发概率 **+20%**。
⇒ **满 5 层即**：全属性穿透 **+50%**、技能威力 **+125%**、武器攻速 **+75%**、武器触发概率 **+100%**。

**这是一个正反馈**：攻速越高 → 普攻段速越快 → 第五段剑气越频繁 → 追加伤害打得越多、[燎原] 越不容易掉；反之，**紊乱断供 = 燎原掉层 = 技能威力与攻速一起回落**，输出曲线会明显波动。

**循环（社区口径，7 溯后基本不变）**：远程上 buff → [残光] 冲进怪群 → 开 [冥焰] → 白嫖一次 [残光] → 同律武器普攻到神智见底 → 宠物技能 + 普攻 / [残光] 回神智 → 再开 [冥焰]。

## 技能升级优先级

- 社区一致：**终结技 [冥焰] 优先**；[残光] 与被动 [回转] 前期点到几级即可。
- 7 溯后理由更强：[伊弥尔] 的剑气倍率与「第五段」都挂在终结技这一支上，**终结技等级 = 追加伤害的基数**。

## 溯源取舍（数据包为准）

- **1 溯**：螺旋跳跃与释放 [残光] 后叠 1 层技能效益 +8%（12 秒、最多 3 层）—— 续航向。
- **2 溯**：对**生命值百分比低于自身**的目标伤害 **+30%** —— 少量加伤档。
- **4 溯**：按自身**连击等级**提攻击，每级 +20%（对应 `贝蕾妮卡4溯`）。
- **6 溯**：使用 [冥焰] 后**释放剑气时有概率额外生成 1 道剑气**，概率 = **[伊弥尔] 触发概率 ×25%** ⇒ 直接抬高剑气产出，**间接服务 7 溯的「第五段命中频率」**。
- **7 溯（开关）**：见上「三段式」。
- ⇒ 取舍口径：**7 溯是把她从「平滑」变「爆发」的开关，必点**；在此之上 **2 溯** 是最划算的加伤档，**6 溯** 与 7 溯有协同（更多剑气 = 更多第五段 = 更多追加与燎原）。

## 已知疑点（务必先看）

1. **⚠️ 数据包里翻不到 [暗属性紊乱] 的施加者。** 全量检索角色表，「暗属性紊乱」**只出现在她第 7 溯这一条描述里**；对照法露茜（火属性紊乱是她自己的被动挂的），**没有任何技能 / 武器描述会施加暗属性紊乱**。
   ⇒ 两种可能，必须实测区分：**① 紊乱是通用机制**（同属性伤害自动叠层）⇒ 贝蕾妮卡自身的同律武器暗属性伤害即可自叠、能自循环；**② 紊乱靠特定来源施加**（角色 / 魔之楔 / 场地 / 敌对单位）⇒ 则必须配一位暗属性紊乱供给者，而当前数据包**没有**这样的角色。
   ⇒ 回答「7 溯强不强 / 怎么配队」时，**先把这一条讲清楚**，不要默认她能稳定吃到 7 溯。
2. **追加伤害的乘区归属**：它同时写着「**暗属性充盈伤害**」与「**视为同律武器伤害**」。按引擎口径，`tag` 含 [充盈] 的伤害整体 ×(1 + 充盈威力) ⇒ 这条追加**很可能吃「充盈威力」**，同时按同律武器伤害结算。⇒ **充盈威力可能是 7 溯后新增的有效词条**，但本技能不代替实算，请在配装页验证。
3. **[燎原] 的维持**：只有「成功消耗紊乱」才刷新，且持续仅 10 秒。紊乱一断就掉层，**技能威力与攻速同时回落** ⇒ 组队时「覆盖率」是主要变量，别只按满层面板算。
4. **编造信息**：市面大量文章给出「**暴击套（狂怒套）**」「**疾风之楔**」「**嗜血套**」「**不屈之楔**」「血怒」「炽阳斩」等名字 —— 这些**在数据包里都不存在**，属纯编造，**一律不采信**；还有把她说成「远程 / 近战双模式」的，也与数据包（精通 单手剑 / 双枪 + 同律武器近战）不符。
5. **官方定位不是登顶**：官方口径是「把老角色拉到**当前梯队可用**的程度」，重点是让她**能正常上场**（满层燎原 +75% 攻速对手感改善明显），而不是做成新天花板。
