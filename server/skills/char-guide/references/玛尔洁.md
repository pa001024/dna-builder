## 一句话定位

火属性**泛用助战辅助**，社区俗称「垃圾桶公主 / 垃圾妹」。靠**两个加攻被动无条件给队友 +85% 攻击**，是当前版本最万能的攻击辅助；本体伤害 / 控制都算赠品。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **全部价值在被动**（社区口径）：被动「玛尔洁的鼓劲小调儿」给队友 **攻击 +45%**，协战「攻袭」给自身与队友 **攻击 +40%**，两条相加 = **无条件 +85% 攻击，只要她在场就生效**（数值以 `read_entry char 3301` 为准）。
- 战技「玛尔洁的万能寻宝铲」**基本没伤害**，价值是**眩晕**（且**不能眩晕精英 / BOSS**）；终结技「玛尔洁的可燃垃圾箱」按 [捡到宝了！] 层数分 3 / 6 / 9 层强化，社区口径「伤害马马虎虎」。
- [捡到宝了！] 靠**自己或队友拾取掉落物**叠层（最高 20 层，加技能威力）——**只对玛尔洁自己生效**。
