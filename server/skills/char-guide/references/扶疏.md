## 一句话定位

水属性**辅助 / 神智回复 / 治疗**，**目前唯一带「神智回复」的辅助**。战技回血回神智、终结技给全队**超限护盾 + 攻速 + [九针治未]（技能威力拐）**，被动给全队**技能速度**。**本身伤害低**，做纯辅助养；是「谁不缺蓝谁就要她」的万金油。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **战技 [提挈浮沉]**：召唤 [召唤物·云螭]，每秒打伤害，**每 3 秒**为周围队友**治疗 + 回神智**。⚠️ 两条关键口径：
  - 云螭的**伤害 / 治疗 / 回神智频率不受「水雾弥散」影响**；
  - 生命 / 神智回复**与云螭每 3 秒的那次攻击同频**，且**不受技能范围影响** ⇒ 所以**技能持续时间要略大于 3 的整数倍**（否则少回一次）。
- **终结技 [形与神俱]**：给自身 / 队友**超限护盾**，自身加**攻速**，队友加 **[九针治未]**（按扶疏自身技能威力比例提技能威力）。⇒ **她的辅助量取决于自己的技能威力面板**，所以「堆技能威力」是她的主线。
- 被动 **[神归心舍]**：自身 / 队友**释放战技 / 终结技后**叠「技能速度」（加快施法）。⚠️ 这是**覆盖率条件**，不是「开得越勤越猛」的因果。
- 被动 **[华英成秀]**：按场上云螭数量**提自身技能威力** ⇒ 用场上召唤物数反哺终结技增益。
- 协战 **[筋脉和同]**：**队内 ≥2 名属性相同的角色**时，给自身与队友**技能伤害提高** —— 与塔比瑟组队即可满足（水系双人）。

## 技能升级优先级

社区口径：**终结技 > 被动（神归心舍）> 战技**。社区补充：**战技（云螭）升级只提奶量、回蓝量不变**，所以战技点到 4 级或 8 级即可，**终结技优先拉满**（技能增伤在终结技上）。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯（社区「绝顶穿透拐」）**：带 **[九针治未]** 的目标造成技能伤害时**无视 30% 防御**。
  ⚠️ **口径冲突**：网传写法称「无视 25% 防御」，**数据包原文是 30%** —— **以数据包为准**。
- **2 溯（社区「回蓝质变」）**：[召唤物·云螭] 最多存在数量**提到 3 个**，回蓝 / 治疗量提升（也相当于给终结技增益再加一档技能威力）。
- **4 溯**：[神归心舍] 叠加上限提高 + 每层给**昂扬**。
- **5 溯**（社区）：终结技等级提升 ⇒ **降低终结技增益所需的技能威力阈值**。
- **6 溯**：终结技攻速效果持续期间，**自身获得 220% 近战普攻水属性追加伤害** —— 偏输出，社区普遍认为**辅助位不必追**。
- ⇒ 结论口径：**1 溯给穿透、2 溯补回蓝、4 溯加技能速度**是辅助位的价值档。

## 已知疑点

- **云螭回蓝频率**不受水雾弥散影响、且**固定第 3 秒** ⇒ 技能持续时间要略大于 3 的倍数，这是最容易被忽略的坑。
- **技能威力有稀释**，紫卡阶段不必死堆技能威力。
- **1 溯的穿透数值口径冲突**（数据包 30% vs 部分站 25%），**以数据包为准**。
- 个别文章把她称为「泽被苍生」并给「云璃治疗机制」等说法，**与数据包技能名不符**，别采信。
- 6 溯输出向收益波动大，**辅助位不要为此堆输出装**。
