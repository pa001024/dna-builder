# 棘刺绝响（太刀登龙通用公式）

> 本文件是**跨角色通用公式**专题，不属于单个角色：从线上构筑 [《菲娜 背水蒙恩对单DPS计算 1.6》](/char/1801/_86KQ653Ih)（更新于 2026-09-17）提炼的「**太刀登龙 + 棘刺绝响**」公式，适用于**所有能精通突击枪的角色**（见「适用角色」表）。各角色文件开头的「🔁 通用公式」节都指向这里。
> **单个角色的最优配装 / 手法 / 队友仍以 `references/<角色名>.md` 与该角色的线上构筑为准**；本文件只给公式共用的**机制链与配装骨架**，以及「哪些槽位照抄、哪些必须按角色重配」。
> 原文取数落点：`read_entry weapon 棘刺绝响 / 蒙恩御礼 / 红叶一滴`（`灾厄熔炼` / `技能字段` / `熔炼`），`read_entry mod 乱花斩月 / 幸运·领界 / 衰朽 / 反转`。

## 一句话公式

近战太刀带魔之楔 `乱花斩月` 把**蓄力攻击**替换成「登龙」多段跳劈；远程带**灾厄突击枪 `棘刺绝响`**，用它的 **5 熔潜能「近战武器蓄力攻击伤害提高 300%」**把登龙放大成主输出；登龙的十几个近战命中段同时喂**灾厄值 → [寂灭]**（1000% 起步的灾厄伤害）做第二出伤线。角色自身的攻击 / 暴击 / 蓄力 / 背水（低血）/ 昂扬 / 增伤类增益全部作用在这两条线上。

## 机制联动链（换算与口径）

1. **登龙**（`乱花斩月`，近战·囚狼·紫，id 106001，**限定：太刀**）：`技能替换字段` = 蓄力突刺 75%×3 ＋ 蓄力攻击 64%×8 ＋ 蓄力攻击终结 190%——一次蓄力 12+ 段、全部吃近战武器伤害结算，综合威力比默认蓄力招式提高 100%（`效果` 原文）。
2. **棘刺绝响（远程·突击枪·灾厄，id 20599）的 5 熔潜能是公式引擎**：`灾厄熔炼` Lv.5「近战武器蓄力攻击伤害提高 300%」（进蓄力增伤加算池，配装侧口径）。⚠️ **潜能仅在角色精通突击枪时生效**（`熔炼` 字段原文「潜能仅在角色的精通武器与该武器类型相同时生效」）——**这是全公式唯一的硬精通门槛**。
3. **灾厄值 → [寂灭]（第二出伤线，全自动）**：`灾厄熔炼` Lv.0：此武器造成伤害 +2 灾厄值（上限 100，满时消耗全部触发 1 次 **[寂灭] = 1000% 灾厄伤害**、视为远程武器伤害并拉怪）；Lv.1 荆刺·争妍：**近战**武器造成伤害 +2、**暴击再 +4** ⇒ 登龙一次十几个暴击段就喂掉小半管灾厄值；Lv.3 荆刺·衰败：每耗 120 连击点数，下次 [寂灭] 倍率 +600%（即 1600%）并给近战伤害 +30%（3 秒）。
4. **连击等级与 [厄运之痕]**：5 熔还把连击溢出与每次 [寂灭]（+20 层）转成 **[厄运之痕]**，蓄力时连击不满可立即消耗补充 ⇒ 蓄力攻击常驻吃满**连击等级**收益（配装侧建模 BUFF「连击蓄力攻击加成」：D/C/A/B/S = 0/100%/300%/400%/700% **独立乘区**——资料检索 `read_entry` 读不到，引用时标「配装侧口径」）。近战魔之楔 `幸运·领界`（52204，满级 100% 概率额外 +1 连击点数）是连击供给的钥匙件。
5. **近战太刀二选一（非灾厄武器，特效始终生效，不要求太刀精通）**：
   - `蒙恩御礼`（10603）满精炼：角色攻击 +100%；**蓄力攻击时暴伤 +150%**（6 秒）——蓄力流标准件（★ 构筑用）。
   - `红叶一滴`（10601）满精炼：暴伤 +125%；造成伤害时**伤害 +18% × 连击等级**——连击流变体（线上出现份数常更多）。
   - 太刀不精通的代价只有「武器攻击 ×1.2 面板系数」（角色基础攻击占大头，影响很小）；**乱花斩月的替换与上述特效照常生效**。
6. **定量占比（线上菲娜构筑属克木桩口径，勿当普适常数）**：一轮「4 普攻 + 1 普攻 + 登龙 + 数次寂灭」约 3.2 秒，其中**登龙 ≈ 8 成、[寂灭] ≈ 1 成、普攻 ≈ 半成**，作者自建的 dot 项可忽略。⇒ 判断某个增益值不值得带，就看它放不放大「近战蓄力 / 武器伤害 / 暴击」。

## 配装骨架（换角色时各槽怎么处理）

| 槽位 | 公式件（通用，照抄） | 按角色重配 |
|---|---|---|
| 近战武器 | 太刀：`蒙恩御礼`（蓄力流）或 `红叶一滴`（连击流），满精炼 | 基本固定 |
| 远程武器 | `棘刺绝响`，**5 熔**（公式核心） | 固定 |
| 近战魔之楔 | `乱花斩月`（机制必带）＋ `幸运·领界`（连击供给） | 其余 6 格放暴击 / 暴伤 / 攻速 / 攻击类数值件（★ 构筑用盛怒 / 专注 / 迅捷 / 攻势系） |
| 远程魔之楔 | `衰朽`（43343：远程伤害时掉血 10%、间隔 1.0 秒——把血线压到 35% 地板，背水方向钥匙件）＋ `反转`（43342：每累计 30 次远程命中 → 近战伤害 +60% / 18 秒；射击间隔 0.18 秒很快叠满） | 其余放数值件；昂扬方向可把 `衰朽` 换掉 |
| 角色魔之楔 / 中枢 | — | **全部按角色重配**：背水方向（★ 构筑 = `全盛·背水` ＋ `炽灼·决断`×5 可叠件 ＋ 中枢 `昂扬`）或昂扬方向；⚠️ 带 `属性` 限定的魔之楔（如 `炽灼·决断` 是光属性限定）必须与角色属性一致 |
| BUFF / 溯源 / 队友 | — | **全部角色专属**：菲娜的溯 / 被动 / Q 追伤与「松露与榛子＋主角-光」增益不通用，换成目标角色自己的 |
| 循环轴 | 4 普攻攒连击 → 1 普攻取消 → 蓄力登龙；[寂灭] 全自动无需手动 | 攻速换算按角色面板重算；作者备注「幸运换快蓄打 4a+2a」收益高个位数百分点但没有攻击范围 |

⚠️ ★ 构筑是「背水 + 属克」口径（300 防、抗 -4、自身 30% 血线）；作者自己给出对照：属克环境 28.46 亿 vs 无属克 7.04 亿——**属克收益取决于各角色自身的属克 / 转属手段**，菲娜的数字（含 6 溯转弱点）不能外推到其他角色。

## 适用角色（谁能用）

**硬门槛只有一条：突击枪精通**（本体精通 / 额外精通选择 / 全部类型）——灾厄潜能与 [寂灭] 线都挂在这上面。**太刀精通不需要**（见机制链第 5 条）。

| 精通情况 | 角色 |
|---|---|
| 精通含突击枪 | 芙罗拉(1102)、主角-暗(1201)、主角-光(1601)、菲娜(1801)、卡米拉(3202)、黎瑟(4101)、SP黎瑟(4103)、煜明(4201)、赛琪(5301)、达芙涅(5401)、莉莉蔻(5402) |
| 额外精通可选突击枪（在配装页选上即可） | 塔比瑟(2301)、扶疏(2401)、法露茜(3104)、海尔法(3201)、玛尔洁(3301)、止流(4102)、兰迪(4202)、西比尔(4301)、奥特赛德(5102) |
| 精通全部类型 | 刻舟(1503) |

- **SP黎瑟 / 莉莉蔻**：数据包技能字段为空、本技能暂无角色文件 ⇒ 只标资格，先不给配装建议。
- ⚠️ **「能用」≠「是该角色的最优解」**：有更强专属流派的角色（法露茜的血染织羽线、赛琪 / 琳恩的同律线、刻舟的 [剑非剑] 流等）优先走本角色文件里的线上构筑口径；把本公式当**通用的出伤骨架 / 过渡方案**。
- 需要复算某个角色套用后的数值 → 那是**配装助手**的活（`run_code` 载入该角色线上构筑改武器与循环重算）；资料检索侧回答机制与骨架即可。

## 边界与诚实

- `乱花斩月` 的 `限定` 是「太刀」，换其他近战武器类型不成立；重剑的对应替换件是 `狂野突刺`（103002），**不属于本公式**。
- 「连击蓄力攻击加成」的 D/C/A/B/S 数值是**配装侧建模 BUFF**，资料检索读不到，别当数据包事实转述。
- 占比与用时数字来自单份线上构筑的属克木桩，随角色 / 敌人 / 版本变；本文件**不提供 DPS 结论**。
- 神智续航、生存、对空短板按角色自查（如刻舟高压环境生存差的备注见其文件）。
