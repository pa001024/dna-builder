## 一句话定位

雷属性**防御 / 护盾辅助**。全角色**唯一拥有可阻挡投射物的〔屏障〕**，是 1.5「扼守高波收益」改动后挂机 99 波皎皎币的**「新晋真神」**；本身输出低，做纯盾辅养，**挂机时技能与溯源甚至可以不点**。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **战技「正当怠工」**：身前持续展开〔屏障〕，展开期间**不能移动、不能使用武器**、持续烧神智、对周围敌人挂〔过劳怨念〕（降攻 + 每 2 秒雷属性持续伤害）；再次使用收回。〔屏障〕**可抵挡来自前方的投射物**并吸收伤害，累计吸收自身最大生命约 100% 后消失。
- **终结技「特殊礼物」**：向前投掷〔特制盾牌〕，停下时 + 之后每 3 秒各触发 1 次〔震撼〕（基于防御、只对护盾生效的伤害），并给自身与队友按防御附加**超限护盾**；若目标护盾已为 0 则**麻痹**。
- **被动（叠防御）**：给队友附加超限护盾时，按自身防御为目标叠「防御提高」层数。
- **被动（刷盾）**：〔屏障〕累计吸收约自身最大生命 70% 的伤害时，消耗神智**刷新〔屏障〕**并补 1 次展开伤害。
- 社区手法（社区口径）：**起跳时再放终结技**可飞更高、躲地面伤害、扔得更远，按攻击键触发〔震撼〕。
- 字段落点：伤害格式是「{防御%}+{}」在 `read_entry char 4202` 技能.字段（战技伤害 / 〔过劳怨念〕持续伤害 / 〔震撼〕伤害与超限护盾）；〔屏障〕〔过劳怨念〕定义在同条 术语解释；「叠防御」层数上限看 被动字段。

## 技能升级优先级

- **挂机向（社区口径）**：**技能与溯源完全不必升 / 点**，只要点出提供〔屏障〕的核心被动即可，**0 溯不影响使用**。
- **常规向**：优先 **战技（正当怠工）与被动**；终结技（震撼 / 麻痹控制）次之（社区通用口径）。

## 溯源取舍

- **1 溯**：〔屏障〕抵挡投射物时给伤害来源挂 1 层〔过劳怨念〕（仅此方式可叠，最多 2 层）。
- **2 溯**：按自身等级每级增加约 50 点超限护盾上限（纯数值）。
- **4 溯**：〔震撼〕命中目标时，结算 1 次目标的〔过劳怨念〕伤害。
- **6 溯**：〔震撼〕命中时额外造成 1 次「自身〔护盾值 + 超限护盾值〕1200%」的雷属性伤害 ⇒ 社区口径「护盾 / 超限护盾越厚终结技越疼」。
- ⇒ 结论口径：**挂机不依赖溯源**；只有当输出向（6 溯）时才值得点。
