## 一句话定位

雷属性**技能输出主 C**。靠战技攒〔泉符〕、再由终结技按符组合成三种形态爆发，社区称「核弹流大 C」；同时因被动能给全队叠昂扬，也能当带增伤的功能位。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **战技「解天机」**：点按 →〔解天机·震〕（前方范围 + 1 枚〔泉符·震〕）；长按 →〔解天机·巽〕（周围范围 + 超限护盾 + 1 枚〔泉符·巽〕）⇒ **点、长按交替就是在配符**，攒符本身倍率不高。
- **终结技「天地演绎」**按手上符的种类组合，替换成三种技能：
  - 双〔震〕→ **震有声**：前方直线爆发，出伤快，但打多动症单目标易空（社区口径，适合怪潮 / BOSS）。
  - 一〔震〕一〔巽〕→ **万物生**：总倍率高、范围大，附带〔雷风齐四方〕领域（领域每 3 秒选敌生成〔雷风相与〕），出伤稍慢、可边喷边输出。
  - 双〔巽〕→ **天地明**：周围范围 + 给自身〔天地明〕技能增伤 buff ⇒ 社区习惯**天地明起手**再决定爆发技。
- **被动（保符）**：消耗〔泉符〕时有概率保留 1 枚，**概率吃近战武器「触发概率」属性** ⇒ 武器魔之楔优先堆触发概率。
- **被动（叠昂扬）**：自身与队友造成雷属性技能伤害时给自己叠昂扬（最多 20 层）⇒ **强绑定雷属性队友**。
- 字段落点：三形态倍率与领域/半径在 `read_entry char 4102` 技能.字段（`[震有声]` / `[万物生]` / `[天地明]` / `[雷风齐四方]领域`）；保符概率公式看 被动字段 `效果概率`；形态切换条件在 终结技 的 术语解释。

## 技能升级优先级

- 社区口径：**Q/E/被动全需要，优先 Q（终结技/天地演绎一族）**。
- 社区给的循环：**开场先两个长按战技 + 终结技**攒增伤 buff → 再「短 + 长 + 终结技」→ 之后「短 + 短 + 终结技」（即按上方三种配符切换）。6溯可省略第一步。

## 溯源取舍

- **1 溯**：〔震有声〕额外触发 1 次〔雷风相与〕（各 60% 伤害）⇒ 直线形态增伤。
- **2 溯**：强化〔万物生〕—— 可点按 / 长按分别释放（点按选取敌人增至 8 名；长按领域变永续、每秒耗 6 神智）。
- **4 溯**：**神智溢出时**给自身与队友叠「攻击提高 16%」，最多 5 层。
- **6 溯**：处于〔雷风齐四方〕领域内时**全属性穿透 +40%**，并持续获得〔天地明〕增伤。

## 队友

- 线上队友以 **煜明 + 扶疏** 为主（推荐构筑同为此组合）；另有 **黎瑟 + 扶疏** / **扶疏 + 菲娜** / **黎瑟 + 煜明**，几份未填队友。
- 机制口径：被动要求「自身与队友造成雷属性技能伤害」才叠昂扬 ⇒ **强绑定雷属性队友**，线上队友（煜明 / 黎瑟）均为雷属性，与机制一致。
- **扶疏**：治疗 / 回神 / 增伤 / 护盾，线上出现频次最高；止流身板不硬且输出不能离怪太远，高压环境需要她的生存位。
- AI 协战口径（社区，未与线上冲突）：止流 AI 不续被动保留的符，只按固定「2 符 1 大」的频率丢技能，输出不如主控；亦有说法称其施法顺序「天地明 → 万物生 → 震有声」偏慢、真空期大。**两种口径并列**。
