## 一句话定位

雷属性**割草对群特化输出**（技能伤害）。核心是终结技开大后自动索敌打〔电荷〕连锁，操作量极低；2 溯后可进挂机阵容。**对单乏力、缺增伤乘区**是社区公认短板。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- 双资源循环：被动把**消耗的神智按比例转成〔电能〕**、又把**消耗的〔电能〕按 50% 转回神智** ⇒ 面板堆上去后能「电表倒转」，配扶疏回神智可近乎永续开大。
- **终结技**进入〔电场爆发〕：每秒随机选取周围 1 名敌人造成雷伤并轮流挂〔正电荷〕/〔负电荷〕（优先选没有〔电荷〕的目标），期间持续烧神智；带相反〔电荷〕的两个目标每 3 秒互相吸聚、吃一次高倍率〔电荷〕伤害。社区口诀把它讲成「正电荷吃两次、负电荷吃一次」。
- **战技**是前冲位移：〔电能〕≥30 时消耗 30〔电能〕强化，提飞跃速度与倍率，并给自身约 90%「造成伤害提高」。既是输出也是跑图手（社区「E 后接瞄准射击保持高速滑行」）。
- 关键约束（社区口径）：**大招的有效范围不吃「技能范围」词条** ⇒ 配装可省范围。
- 字段落点：倍率在 `read_entry char 4101` 的 技能.字段（`[电场爆发]选取敌人伤害` / `[电荷]伤害` / 战技两级倍率）；资源循环看两条被动 `转化比例`；约束条件看同条 术语解释（〔电场爆发〕〔电荷〕定义）。

## 技能升级优先级

社区口径：**终结技优先满，战技与被动可停 6/8 级**，资源充裕再升满。

## 溯源取舍

- **1 溯**：〔电荷〕伤害由单体变半径 3 米范围 ⇒ 起手对群。
- **2 溯**：**核心门槛** —— 带〔电荷〕的敌人被击败时，把〔电荷〕按剩余时间传给周围 20 米目标 ⇒ 秒杀小怪可连锁清场，也是「能顶替召唤位进挂机队」的前提。
- **4 溯**：开场自带 50% 最大神智的〔电能〕。
- **6 溯**：〔电场爆发〕每秒选取的敌人由 1 名增至 2 名。
- ⇒ 口径：**0~1 溯偏跑图、2 溯起步、4 溯提升很小、6 溯强化对群**。

## 队友

- 线上队友以 **菲娜 + 扶疏**、**止流 + 煜明**、**扶疏 + 煜明** 三类为主（新推荐为 `煜明 + 止流` 三雷挂机）；另有 **煜明 + 伊薇** / **达芙涅 + 菲娜** 等个别组合（「艾达」即伊薇的社区旧称）。
- 机制口径：**扶疏回神智**，是撑住黎瑟大招与双资源循环的核心（挂机 / 手操通用）。
- **煜明** 作副 C / 辅助时，电场能直接触发〔酣战〕、击杀触发电荷传染，是挂机高波 / 探险向的常见搭档；**止流** 在三雷挂机里是实际输出位（作者口径：止流 ＞ 煜明 ＞ 黎瑟辅助）。
- 黎瑟也可作挂机队主控；但因对单弱，高难 / 精英 BOSS 表现不如特化角色。
