## 手法

- **对单 / 共斗**（社区口径）：每个新 BOSS **先按终结技**上 [处决目标] → **近战普攻穿插重击**叠 [火属性紊乱] 层数与 [觉醒值] → 当 [觉醒值] ≥ **15000**（对应 `falsi-build` 里的「消耗阈值」）且目标紊乱 ≥ **3 层**时，**释放战技**结算紊乱伤害，循环。
- 层数图标（社区口径）：3 层 [火属性紊乱] = 半圆图标，6 层 = 整圆图标。
- **低溯源叠满再放战技**输出最大化；**6 溯叠到一半即可穿插**技能。
- 联袂模式换 BOSS 会**断标记**（出现放战技却不消耗紊乱层数的情况），**重新按终结技**即可。
- ⚠️ 177xz 口径「配鞭刃打近战群怪、切双枪打远程爆发」——数据包法露茜精通是**双刀 / 双枪**，并不精通鞭刃，此条属社区泛述，具体以 `read_entry char 3104` 为准。
