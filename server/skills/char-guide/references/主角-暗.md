# 主角-暗（狩月人 · 暗）

> 数据包内名 **主角-暗**，`char id 1201`，属性「暗」，标签「输出 / 武器伤害」，精通「单手剑 / 突击枪」。技能 / 溯源原文都在 `read_entry char 1201` 里，本文件不重复原文。
> 版本：1.0。社区一般不叫「主角-暗」，而是统称 **「暗主」**（对照「水主 / 光主」）——**检索时两个词都要试**。
> 本文件为**社区口径汇总**，配装结论**只作方向参考**。

## 一句话定位

暗属性**武器输出 / 半辅助**：既能当主控承担输出（靠 [漆黑之手] 协同攻击），也能交给 AI 当**暗队辅助**（回神智 + 连击点数供给）。是**贝蕾妮卡社区的「必带队友」**（见其文件）。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **[漆黑之手]** 是核心协同攻击手段，其**伤害与伤害半径都吃「技能范围」** ⇒ 社区口径：**主控暗主优先堆技能范围**来放大 [漆黑之手]。
- 被动 **[回魂]** 触发 [漆黑之手] 需要累计近战普攻次数（具体次数看 `read_entry`，由溯源改写）。
- **连击点数**是她给队友输送的资源（社区口径：靠蓄力攻击把连击点数分给队友）。
- 终结技 [雾海祷音] 在 2 溯后**生成减速 + 每秒伤害的领域**（[暗色棱镜]），因此社区有「2 溯后重点堆技能范围」的玩法。

## 技能升级优先级

社区口径：**资源紧缺时全技能先到 8 级；资源充足后全部点满（10 级）**；额外被动优先解锁 **挽歌**（核心增伤），其余额外被动一并解锁升级。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：[回魂] 触发 [漆黑之手] 时自身获得 20 连击点数 —— 加快连击积攒。
- **2 溯**：终结技生成 [暗色棱镜] 领域（减速 + 每秒伤害）—— 社区称「解锁后重点堆技能范围」。
- **4 溯**：[回魂] 触发所需近战普攻次数**由 8 次下调至 6 次**。
- **6 溯**：[回魂] 触发次数**由 1 次提升到 3 次** + 触发时获得 25% 全属性穿透 —— 社区认为输出频次与穿透双收益。
- ⇒ 结论口径：**1 / 2 / 4 / 6 溯都是有效档**。

- 线上 4 份里有登记队友的两份都是 `菲娜` + `芙罗拉`，推荐构筑同为此组合；样本小，不足以下结论。

- ⇒ 反向落点不变：**贝蕾妮卡侧的「必带主角」= 主角被动里的武器伤害提高**；但注意线上贝蕾妮卡 6 份里并没有带主角（见其文件），这条属机制口径而非线上实况。
