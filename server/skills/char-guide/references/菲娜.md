# 菲娜（夜莺千夜谭）

## 一句话定位

光属性**武器伤害增伤辅助 / 复合型辅助**，社区公认 **T0 泛用辅助**：终结技给队友挂**水 / 火 / 雷 / 风四属性追加伤害**（追伤，按队友武器攻击结算的独立乘区），被动叠 **[梦笔生花]** 给全队增伤。**0 命即发挥核心价值、2 溯辅助毕业、6 溯可转主控**。⚠️ **追伤只对武器 / 同律武器伤害角色吃满，对纯技能流角色增益有限**。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

菲娜是这条公式的**模板角色**（精通含突击枪、额外精通选太刀）：线上 ★ 构筑《背水蒙恩对单DPS计算 1.6》就是公式本体；近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **终结技（社区简称 Q）** 是辅助核心：给队友分别附加**水 / 火 / 雷 / 风四属性追伤**（**基于队友武器攻击、按固定倍率 ×4 段独立乘区**），脚下生成 **领域 [喧闹下午茶]** 打持续伤害（社区口径「**倍率极低，仅作补充**」）。
  - 操作细节（社区口径）：**连续按终结技可切属性，切换无动画 / 无硬直，并刷新所有追伤持续时间**；追伤状态与领域属性显示在屏幕中下方。
  - ⚠️ 领域时效口径：**「领域展开队友就能吃到追加 BUFF，和领域范围无关」** ⇒ 所以**官方标黄的「技能范围」并没有那么重要**，别死堆范围。
- **战技（社区简称 E）**：也是叠 [梦笔生花] / 触发增伤的来源；实战主控可**连放战技加速被动增伤叠层**。
- **被动 [梦笔生花]**：靠开终结技（1 层）与放战技（每多用一个战技约 +6 层）往上叠，**满层给全队约 +30% 伤害提升**。

## 技能升级优先级

- **多方一致**：**大招 / 被动优先，战技最末** —— 「大招 > 被动 > 战技」。
- **社区口径**：**大招 > 被动2 > 战技 > 被动 1**。
- ⚠️ 社区补充：**战技的材料可以省出来**，低练菲娜只点大招与被动即可。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：带 [喧闹下午茶] 追加伤害的目标，**每带 1 种属性追伤效果 ⇒ 全属性穿透 +6%** ⇒ 四属性全挂时约 **+24% 全属性穿透**（社区口径「打无属性敌人约 +24%，对溯源赛琪约 +16%」）。
- **2 溯（辅助毕业档）**：**[梦笔生花] 层数上限提高 + 领域期间每秒额外叠层** ⇒ 社区口径「**增伤上限 30% → 45%，自身追伤 45% → 60%**」，是**辅助位的毕业门槛**。
- **4 溯**：**每层 [梦笔生花] +2% 技能威力、+1% 技能范围** —— 偏**自身输出上限**（社区口径「满溯给 90% 技能威力 + 部分技能范围，追伤 60% → 114%」）。
- **6 溯（主控必备）**：领域期间武器伤害**每种属性 +24% 暴击率**，并把**元素属性伤害转为目标弱点属性** ⇒ 社区口径「**至少 120% 武器伤害暴击率常驻**，可转主控」；⚠️ **深渊不朽剧目暂不生效**。
- ⇒ 结论口径：**0 命可用、1 溯给穿透、2 溯辅助毕业、4 溯转输出、6 溯主控**。

## 队友

- 线上队友以 `主角-光 + 松露与榛子`、`扶疏 + 主角-光` 两类为主，个别只带 `扶疏`，另有多份未填队友；推荐构筑为 `松露与榛子 + 主角-光`。
- 实况里最常同框：`主角-光`、`松露与榛子`、`扶疏`。
- ⚠️ 旧稿主推的「赛琪 / 琳恩 / 莉兹贝尔 / 奥特赛德」等主 C 在线上没有出现 —— 无可对上的实况，**以线上为准，不再作为配装建议**。
- ⚠️ **追伤只对武器 / 同律武器伤害角色吃满**，纯技能流吃不全（机制结论）。

## 已知疑点（社区未定论，不要当结论讲）

- **追伤适用范围**：**只对武器 / 同律武器伤害角色吃满**（多方一致），技能流吃不全 ⇒ 回答「菲娜值不值得带」时**先说清主 C 类型**。
- **领域范围无关**（社区口径）vs 另有说法强调「范围」——理论上**追伤看的是队友是否持有 BUFF**，**范围主要影响领域伤害**；两条口径并列，别单方面下结论。
- **专武触发概率低**（15% → 堆满约 50%），弹药回不满是共识痛点。
- **生存 / AI 短板**：高层副本无回血角色时续航压力大，且**AI 逻辑较差、易快速耗蓝、不会聚怪**。
- **6 溯转主控**需重配输出向魔之楔，与辅助配装不同套。
