## 一句话定位

雷属性**最大生命 / 技能输出**，靠主动打出的〔召唤物·紊乱雷球〕链接敌人、把伤害「隔山打牛」地传出去，属**间接输出 / 生命值核心**。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- 资源是**〔万钧之势〕**（上限 300，2 溯提到 600）：造成伤害触发额外效果时获得，消耗它强化战技与召唤。
- **战技「夺神权柄」**：面前范围伤害 + 生成〔军团惩戒〕领域（生成 1.5 秒后每约 0.4 秒消耗〔万钧之势〕、随机打 1 名敌人，最多持续 10 秒、最多同时 3 个领域）；消耗约 20〔万钧之势〕可强化。
- **召唤「指尖风暴」**：召唤〔召唤物·紊乱雷球〕（同时最多 1 个）。雷球**按比例继承自身最大生命**、防御为 0、**被视为敌方单位**；召唤后每 3 秒触发〔灭顶风暴〕，并链接周围最多约 10 名敌人（逐个增加），对链接目标每秒造成雷伤，同时把自身受到的伤害按比例传递给被链接目标。消耗约 100〔万钧之势〕召唤强化的雷球（触发间隔降到约 2 秒、链接伤害提升）。
  - 社区口诀：**「战技=踩、召唤=球」**，主要输出来源是**球**；她是少见「不需要直接打敌人、而是打自己那颗球」来输出的角色。
- **被动（触发）**：〔夺神权柄〕与〔军团惩戒〕的伤害可触发雷属性额外效果，**触发概率 = 自身近战武器的触发概率** ⇒ **绑近战武器堆触发概率**。
- 字段落点：倍率格式是「{最大生命%}+{}」在 `read_entry char 4301` 技能.字段（`[召唤物·紊乱雷球]链接伤害` / `强化链接伤害` / `[灭顶风暴]伤害` / `[军团惩戒]伤害`）；〔军团惩戒〕〔紊乱雷球〕〔灭顶风暴〕定义在同条 术语解释。

## 技能升级优先级

- 社区口径：**优先召唤（指尖风暴），但被动与伤害技能的等级不要差太多**（被动负责补伤）。

## 溯源取舍

- **1 溯**：雷球受到〔夺神权柄〕与〔军团惩戒〕伤害时，伤害传递比例 +2%。
- **2 溯**：〔万钧之势〕上限提高至 600；且每 1 点〔万钧之势〕令〔军团惩戒〕伤害 +0.1%、令雷球传递比例 +0.01% ⇒ 社区称「上限 600 提升较大，算核心机制」。
- **4 溯**：〔军团惩戒〕每次造成伤害时，20% 概率再触发一次。
- **6 溯**：雷球链接某目标时，若该目标为**首次被链接**，额外造成 1 次 500% 倍率的〔军团惩戒〕伤害，且必须触发雷属性额外效果 ⇒ 社区「质变 / 秒杀」档。
  - 另有「秒杀可无视链接 CD 连续触发」的说法，属**社区猜想，未证实**。
- ⇒ 社区口径：**要练就点到 2 溯**。
