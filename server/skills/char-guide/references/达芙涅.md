## 一句话定位

风属性**辅助 / 控制 / 治疗**。战技 [翠玉弥散] 造**范围治疗 + 减速烟雾场**；终结技 [互斥炼成] 给队友**治疗 + 风属性追加伤害**、给敌人**束缚 + 降攻 + 持续风伤**。核心是把风属性 / 武器输出的增伤给出去 → 社区定位「**武器伤害辅助**」，最搭**高频远程 / 同律武器**主 C。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**精通含突击枪**（灾厄潜能的硬门槛，无需占用额外精通），可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **[翠玉弥散]（战技）**：自身获得该效果，范围内自身 / 队友**持续回血**、敌人**减速**；持续期间**每秒获得 [阿佐特弹]**。
- **[互斥炼成]（终结技）**：对自身 + 队友**治疗**并附 **[净化配方]**（给队友**风属性追加伤害**）；对周围敌人**束缚**并附 **[腐朽配方]**（降攻 + 每 2 秒风持续伤害）；按生效友 / 敌目标数总和获得 [阿佐特弹]（最多 12 发）。
- **[阿佐特弹]（被动）**：持有期间**远程武器触发概率提高**，每次远程射击消耗 1 发，上限 30 发。
- **[银泪销蚀]（被动）**：持有 [阿佐特弹] 时，**远程武器造成伤害额外结算 1 次目标的 [腐朽配方] 持续伤害**，结算倍率基于自身**远程武器触发概率** ⇒ 社区口径「**触发概率 + 多重 + 弹容量**」自循环。
- **[奋激]（协战）**：自身和队友**暴击率提高** ⇒ 对同律 / 远程 C 收益可观（对赛琪）。

## 技能升级优先级

- 社区口径：**终结技 > 战技 > 被动**（增伤在终结技的 [净化配方]）。
