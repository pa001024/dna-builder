## 一句话定位

火属性**坦克 / 嘲讽位**（社区口径「纯粹的坦克」）：靠被动堆最大生命 + 回血，用战技「灼热地狱」的 [裁罚] 打持续火伤，终结技「绝望牢笼」嘲讽拉仇恨。

## 🔁 通用公式：太刀登龙 + 棘刺绝响

本角色**额外精通可选突击枪**——配装时把额外精通选成突击枪后门槛才成立（灾厄潜能仅在精通突击枪时生效），之后即可套用「太刀登龙 + 棘刺绝响」通用公式：近战太刀 + 魔之楔 `乱花斩月` 把蓄力攻击替换成「登龙」多段跳劈，远程灾厄突击枪 `棘刺绝响` 5 熔「近战武器蓄力攻击伤害提高 300%」把登龙放大成主输出、[寂灭] 自动补第二出伤线；**太刀无需精通**（非灾厄武器特效始终生效）。机制链 / 配装骨架 / 数值占比 / 适用角色表见 [棘刺绝响](棘刺绝响.md)；与本角色专属流派孰优，以本文件线上构筑口径为准。

## 机制读法（社区口径，用于理解提问）

- **唯一输出来源是战技 [裁罚]**（按自身最大生命造成持续火伤）；终结技**伤害极低**，主要功能是**嘲讽**——**不聚怪，会把怪打散**。
- [裁罚] 可通过**自身受击延长持续时间**，延长收益吃**技能耐久**（社区口径）⇒ 社区配装思路是「延长灼烧时间、扩大覆盖范围」。
- **神智上限低（120）+ 战技 / 终结技消耗高**，开不了几次。

## 技能升级优先级

- **社区口径**：**【灼热地狱】>【惩戒决意】>【绝望牢笼】**；「终结技升级几乎没意义」。
