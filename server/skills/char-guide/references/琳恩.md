# 琳恩（封锁的躁动）

> 数据包内名 **琳恩**，`char id 3101`（属性 / 标签 / 精通都在 `read_entry char 3101` 里，本文件不重复原文）。数据包 **`专武` 字段为空**；其同律武器 **「汉塞尔与格雷特」**（远程 / 双枪）登记在 `同律武器` 字段里。
> 版本：1.0 实装。数据包 `标签` = 输出 / 同律武器 / 武器伤害。
> 本文件为**社区口径汇总**，配装结论**只作方向参考**，条目名随版本变动，引用前建议 `read_entry` 复核。

## 一句话定位

火属性**远程站桩主输出**，社区俗称「女枪」（开终结技后站场倾泻火力得名）。对群是当前版本的顶格清杂手：战技挂 [裂伤]、终结技持续射击、靠裂伤结算出伤。

## 机制读法（社区口径，用于理解提问）

- 出伤围绕**终结技「火药酬宾」**：开启后站桩、持续掉神智、受击免僵直，并持续射击（射击走技能判定）。
- **战技「致命绽放」**负责给目标挂 [裂伤]，被动「战术速射」用 [预装填] 叠增伤；社区把它概括为「先战技挂裂伤 → 开终结技扫射 → 引爆裂伤」。
- 社区流派「**电锯流**」= 用远程武器 **归墟棘轮**（社区外号「电锯 / 锯片炮」）触发高频裂伤，把对单输出拉起来。⚠️ 这是社区叫法，不是技能名。
- ⚠️ **「专武」口径**：数据包里琳恩并无 `专武`；社区说女枪的「专武」指的是她的**同律武器「汉塞尔与格雷特」**。回答「女枪要不要专武」时先确认问的是哪一把。

## 技能升级优先级

- **社区口径**：优先**终结技（火药酬宾）满级**，战技与被动可停 6 / 8 级。
- **社区口径**：**终结技 > 战技 = 被动**（战技、被动与裂伤机制绑定，有资源一起升）。
- ⇒ 两种口径都指向「终结技优先」，分歧只在战技 / 被动要不要同步满。

## 溯源取舍

- 数据包 1–6 溯逐条见 `read_entry char 3101`。社区给的**关键节点是 1 / 2 / 6**：
  - **1 溯**：进战斗即启动被动 + 昂扬，社区认为提升明显。
  - **2 溯**：开终结技期间减伤 + 攻速叠层间隔缩短（社区口径「缩到 1/3」）。
  - **6 溯**：**质变** —— 终结技射击自动叠 [裂伤]，社区口径「输出翻倍」。
- **社区口径**：命座**可停 2 命，也可拉满 6 命**；4 命（对半血以下目标增伤）与 6 命对输出增幅都大，「想拿女枪 C 深渊可以拉满」。
- ⇒ 结论口径：**0 溯可玩、2 溯够用、6 溯拉满**。

## 队友

- 线上队友没有固定搭配：`菲娜 + 扶疏` 略多，另有 `松露与榛子 + 扶疏`、`卡米拉 + 菲娜`，个别不带队友。

## 已知疑点

- **同律武器第四格（多重 vs 攻速）**：见上，口径互相打架且涉及热修，**不要单方面下结论**。
- **强度榜分歧**：社区强度榜把琳恩列 T0.5（强势拼图），社区把琳恩列 T1（输出）。差异源自「对群强、对单依赖电锯」，引用时说明测评环境。
- **神智压力**：社区与一图流都强调「需规划神智」，站桩掉神智快，配装要兼顾续航。
