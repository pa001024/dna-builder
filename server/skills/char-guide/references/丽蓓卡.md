# 丽蓓卡（纯爱蜇刺）

> 数据包内名 **丽蓓卡**，`char id 2101`，`专武 10201`（「塞壬的拥吻」，近战长柄）。属性 / 标签 / 精通 / 溯源原文都在 `read_entry char 2101` 里，本文件不重复原文。
> 版本：1.0；**第 7 溯源已实装**。
> 本文件为**社区口径汇总**。

## 一句话定位

水属性**召唤流技能输出**：召唤海月水母自动索敌叠 [爱之毒]，终结技按毒素层数引爆。操作量低、对群强，是社区公认的**挂机刷图核心**（戏称「轮椅角色」「水母女王」）；短板在**多部位 / 飞行 BOSS**（水母易丢目标）。

## 机制读法（社区口径，用于理解提问）

- **[爱之毒]**：普攻与水母命中都可叠层，每 2 秒结算一次持续伤害，**叠满且目标死亡时毒会扩散**给周围敌人 → 这是她清群的根。
- **终结技**按目标身上 [爱之毒] 层数提倍率，且**不清除毒层**（社区口径）⇒ 所以「先叠毒、再引爆」是唯一正确顺序。
- 水母**继承角色全部属性**、有**独立攻速区间**（初始攻击间隔约 2.7 秒）；带 **水雾弥散** 后水母攻速**改受近战武器攻速影响**（社区实测缩到约 2.1 秒）⇒ 这是「近战武器堆攻速」的根据。
- 实操提示：**技能范围不是越大越好** —— 挂机 / 站桩场景下小范围反而更容易捡材料。

## 技能升级优先级

**口径冲突，两种并列**：

- 一种口径：**召唤 > 伤害 > 被动**。
- 另一种口径：**纯爱试炼（被动）> 爱神蜜露（终结技）> 缠绵之触（战技）**。
- ⇒ 回答「先升哪个」时给方向：**优先保证召唤与叠毒机制，再补终结技倍率**，具体顺序按上面两种口径都提，并让其按资源实定。

## 溯源取舍（数据包为准，标注社区口径）

- **2 溯（社区「质变」）**：水母上限提到 5 个，[爱之毒] 上限提到 8 层。
- **4 溯**：降低来自带 [爱之毒] 目标的伤害 30%（偏生存）。
- **6 溯**：击败带毒目标获得攻击提升（可叠层，刷新时间）—— 社区称「锦上添花」。
- **7 溯（社区「必点」）**：水母攻击**高概率直接附加 8 层 [爱之毒]**（概率吃**近战武器暴击率**）+ 30% 概率额外结算一次 [爱之毒] + **场上每个水母给自己和水母 +12% 伤害**。
  ⇒ 数据包对 7 溯的定义在 `read_entry char 2101` 第 7 条，**不要凭社区复述数值**。
- ⇒ 结论口径：**0 溯能玩、2 溯质变、6 溯锦上添花、7 溯必点**。
