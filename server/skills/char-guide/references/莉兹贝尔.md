> 数据包内名 **莉兹贝尔**，`char id 1501`（属性 / 标签 / 精通 / 同律武器 / 溯源原文都在 `read_entry char 1501` 里，本文件不重复原文）。数据包 `标签` = 输出 / 同律武器 / 武器伤害，`精通` = 重剑 / 霰弹枪，`额外精通` 含太刀。数据包 **`专武` 字段为空**；其同律武器 **「萨麦尔」**（近战 / 重剑）登记在 `同律武器` 字段里。

## 一句话定位

光属性**近战同律武器输出**：开终结技切换 [萨麦尔] 巨剑形态，靠**蓄力攻击**叠连击等级（社区记 C-B-A-S）换爆发，连击越高蓄力斩击倍率与攻击范围越夸张。**极致对群、割草体验顶级**，但攻速慢 ⇒ 对单弱、依赖神智管理。是免费获取（「迷津」通关）的开荒清场手。

## 机制读法（社区口径，用于理解提问）

- 出伤全部围绕**终结技 [我不忍啦！]**：切换近战同律武器 [萨麦尔]，蓄力攻击**消耗神智**换连击点数，连击越高蓄力斩击倍率越高（S 级范围极大）。⚠️ 社区口径「技能威力占她输出 100%」——**技能效益只决定蓄力耗神智，不决定伤害**。
- **被动 [哼！！]**：连击等级提高时强化 [萨麦尔]（攻击范围 + 触发概率），**失去连击等级后强化还额外持续一段时间** ⇒ 所以**技能耐久**能延长这段时间，是词条落点。
- **被动 [越想越气！！！]**：S 级连击蓄力后，[不坚忍]（霸体 + 减伤）额外持续。
- **战技 [以坚忍之名]**：位移技能，本体伤害很低，主要用来跑图和触发 1 溯的攻击 buff（社区口径「位移距离太长经常丢伤害」）。
- **协战 [朱辉散射]**：自身与**光属性队友**攻击提高（仅协战登场生效）。
- 社区把它总结成两条玩法线：
  - **大招流**（0 溯可用）：开终结技 → 走位/普攻聚怪 → 连击较高（**最好逢十**）时蓄力 → S 斩击。武器「枯朽 + 赘生」是稳妥过渡。
  - **太刀登龙流**（**需 2 溯**，社区口径）：靠**远程武器脱手叠连击**（花弓 / 电锯 / 销骨），近战带**太刀红叶一滴**打蓄力登龙，做到「无限 S 连击」。⚠️ **数据包 `精通` 是重剑 / 霰弹枪，太刀只在 `额外精通` 里** —— 这门玩法的近战位用太刀属「额外精通」方向，引用时要点明这层关系，别当成数据包专精。

## 技能升级优先级

- **大招流**（社区口径）：**终结技 [我不忍啦！] > 被动 [哼！！] > 战技 [以坚忍之名]**；战技无伤害，**升到 4 级点出分支即可**。
- **2 溯 / 太刀流**（社区口径）：**优先点满被动，再考虑大招**，战技可不点。
- ⇒ 两种口径的分歧只在「先大招还是先被动」，取决于你有没有 2 溯。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：释放战技后自身攻击 +35%（15 秒）。社区口径：光属性魔之楔已给高额攻击力，**这条实际提升很小**，仅用来偶尔放技能调整位置。
- **2 溯（核心质变）**：**造成伤害触发额外效果时额外 +1 连击点数**，且**不限伤害来源** ⇒ 可以用远程武器「白嫖」连击，这才是「无限登龙/无限 S 连击」的开关。
- **4 溯**：连击等级提高时额外 +5 连击点数 —— 2 溯的加强版，**叠满更快**。
- **5 溯 / 3 溯**：常规加技能 / 被动等级。
- **6 溯**：释放终结技与 [萨麦尔] 蓄力攻击后获得 **30% 光属性追加伤害**（15 秒）。社区对 6 溯价值有分歧：一图流认为「后续无需强求 6 溯」，社区评论区则认为「6 溯是真伤害提升」。
- ⇒ 结论口径：**0 溯可玩（大招流）、2 溯质变、4 溯提速、6 溯拉上限但不强求**。
