> 数据包内名 **莉兹贝尔**，`char id 1501`（属性 / 标签 / 精通 / 同律武器 / 溯源原文都在 `read_entry char 1501` 里，本文件不重复原文）。数据包 `标签` = 输出 / 同律武器 / 武器伤害，`精通` = 重剑 / 霰弹枪，`额外精通` 含太刀。数据包 **`专武` 字段为空**；其同律武器 **「萨麦尔」**（近战 / 重剑）登记在 `同律武器` 字段里。

## 一句话定位

光属性**近战同律武器输出**：开终结技切换 [萨麦尔] 巨剑形态，靠**蓄力攻击**叠连击等级（社区记 C-B-A-S）换爆发，连击越高蓄力斩击倍率与攻击范围越夸张。**极致对群、割草体验顶级**，但攻速慢 ⇒ 对单弱、依赖神智管理。是免费获取（「迷津」通关）的开荒清场手。**1.6 第七根源（7 溯）实装后蓄力轴完全体**：连击点消耗回 90% ＋ [冲动] 常驻面板（见「溯源取舍」）。

## 机制读法（社区口径，用于理解提问）

- 出伤全部围绕**终结技 [我不忍啦！]**：切换近战同律武器 [萨麦尔]，蓄力攻击**消耗神智**换连击点数，连击越高蓄力斩击倍率越高（S 级范围极大）。⚠️ 社区口径「技能威力占她输出 100%」——**技能效益只决定蓄力耗神智，不决定伤害**。
- **被动 [哼！！]**：连击等级提高时强化 [萨麦尔]（攻击范围 + 触发概率），**失去连击等级后强化还额外持续一段时间** ⇒ 所以**技能耐久**能延长这段时间，是词条落点。
- **被动 [越想越气！！！]**：S 级连击蓄力后，[不坚忍]（霸体 + 减伤）额外持续。
- **战技 [以坚忍之名]**：位移技能，本体伤害很低，主要用来跑图和触发 1 溯的攻击 buff（社区口径「位移距离太长经常丢伤害」）。
- **协战 [朱辉散射]**：自身与**光属性队友**攻击提高（仅协战登场生效）。
- 社区把它总结成两条玩法线：
  - **大招流**（0 溯可用；**7 溯后为完全体**）：开终结技 → 走位/普攻聚怪 → 连击较高（**最好逢十**）时蓄力 → S 斩击。武器「枯朽 + 赘生」是稳妥过渡。1.6 起 7 溯让连击点近乎无限、[冲动] 常驻（数据包原文见「溯源取舍」），线上 ★ 构筑的手法就是「除了用战技续 buff 外一直蓄力」。
  - **太刀登龙流**（**需 2 溯**，社区口径）：靠**远程武器脱手叠连击**（花弓 / 电锯 / 销骨），近战带**太刀红叶一滴**打蓄力登龙，做到「无限 S 连击」。⚠️ **数据包 `精通` 是重剑 / 霰弹枪，太刀只在 `额外精通` 里** —— 这门玩法的近战位用太刀属「额外精通」方向，引用时要点明这层关系，别当成数据包专精。线上实证见 [《莉天帝》](/char/1501/ycKVAwWAuA)（1.4 时点，未挂 7 溯）。
- **连击点启动（7 溯循环的前置）**：近战侧走通用规则——**非蓄力攻击（普攻 / 下落 / 滑行）每次命中获得连击点数、命中多个目标重复计点**，可被 `幸运` 系 MOD 加成（`幸运·领界` 52204 / `幸运` 32202，满级 100% 概率额外 +1 点）⇒ 聚怪后普攻攒点效率最高。她还有专属攒点：终结技 [我不忍啦！] 原文「使用[萨麦尔]进行蓄力攻击需要消耗神智，可以**长按维持蓄力状态**，蓄力期间获得[不坚忍]，**每 0.5 秒消耗神智并获得连击点数**」「长按结束、神智不足或**连击等级达到最高**时释放蓄力攻击」⇒ 长按维持蓄力即每 0.5 秒耗神智换点，连击等级到顶自动释放，攒到 S 即进入 7 溯返还循环。远程帮攒（社区口径）：花弓 `茵布拉花序` 蓄力、`若华的飞光` 带加速类魔之楔。机制总纲见本技能 SKILL.md 的「近战连击机制」节。

## 技能升级优先级

- **大招流**（社区口径）：**终结技 [我不忍啦！] > 被动 [哼！！] > 战技 [以坚忍之名]**；战技无伤害，**升到 4 级点出分支即可**。
- **2 溯 / 太刀流**（社区口径）：**优先点满被动，再考虑大招**，战技可不点。
- ⇒ 两种口径的分歧只在「先大招还是先被动」，取决于你有没有 2 溯。

## 溯源取舍（数据包为准，标注社区口径）

- **1 溯**：释放战技后自身攻击 +35%（15 秒）。社区口径：光属性魔之楔已给高额攻击力，**这条实际提升很小**，仅用来偶尔放技能调整位置。
- **2 溯（核心质变）**：**造成伤害触发额外效果时额外 +1 连击点数**，且**不限伤害来源** ⇒ 可以用远程武器「白嫖」连击，这才是「无限登龙/无限 S 连击」的开关。
- **4 溯**：连击等级提高时额外 +5 连击点数 —— 2 溯的加强版，**叠满更快**。
- **5 溯 / 3 溯**：常规加技能 / 被动等级。
- **6 溯**：释放终结技与 [萨麦尔] 蓄力攻击后获得 **30% 光属性追加伤害**（15 秒）。社区对 6 溯价值有分歧：一图流认为「后续无需强求 6 溯」，社区评论区则认为「6 溯是真伤害提升」。
- **7 溯（1.6 实装 · 第七根源，数据包原文）**：[萨麦尔] 蓄力攻击**消耗连击点数时，回复消耗量的 90%**；连击等级 S 释放蓄力攻击后获得 1 层 **[冲动]**，持续 10 秒、**最多 5 层且叠加时刷新**，**每层技能威力 +12%、全属性穿透 +5%** ⇒ 满层 **技能威力 +60% ＋ 全属性穿透 +25%** 常驻。
  - 社区 / 线上口径：这是蓄力轴的**核心质变**——2 溯解决「连击点从哪来」（远程白嫖），7 溯解决「连击点 / 蓝耗撑不撑得住」＋ 给出常驻大额面板。**1.6 的四份蓄力轴构筑（★ / 新咖喱棒 / 灾厄 / 共斗粉毛）全部挂 7 溯**。⚠️ 90% 返还**需要启动过程**（先攒连击点、先爬等级），启动手段见「机制读法 · 连击点启动」与总纲「近战连击机制」。
  - ⚠️ 「7 溯材料来源与限时兑换」属运营信息，会过期，不要复述为现状（数据包 `溯源` / `第七溯源消耗` 只收录效果）。
- ⇒ 结论口径：**0 溯可玩（大招流）、2 溯质变、4 溯提速、6 溯拉上限；7 溯（1.6）= 蓄力流完全体、1.6 构筑标配**。

- 线上 6 份**全部带 `菲娜`**；`扶疏` 见于 5 份（★ / 新咖喱棒 / 共斗粉毛 / 灾厄 / 260亿核爆）、`松露与榛子` 2 份（灾厄构筑、莉天帝）。

## 已知疑点（社区未定论，不要当结论讲）

- **太刀登龙流 vs 数据包 `精通`**：见上，太刀属「额外精通」链路，别把「莉兹贝尔专精太刀」当数据包事实。
- **霸体 BUG**（社区口径）：进阶被动给的霸体，**「有被动时也会被肘」**，社区认为待修。
- **对单能力差**：攻速慢导致对单极难叠连击，消耗神智换连击也不能长久 ⇒ 定位主战场是群怪。
- **1 期戏剧无专属 BUFF**：早期有说法称她前期偏平庸，属版本阶段性口径，**会过期**。
