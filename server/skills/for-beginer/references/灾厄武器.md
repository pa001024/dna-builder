# 灾厄武器 · 刷取与配队

4 把灾厄武器分属两条刷取线：**深境探险出 1.4 两把，深境扼守出 1.5 及之后**。

| 武器 | id | 版本 | 类型 | 原型出处 |
|---|---|---|---|---|
| 无止无休 | `10299` | 1.4 | 近战 · 长柄 | **探险** |
| 棘刺绝响 | `20599` | 1.4 | 远程 · 突击枪 | **探险** |
| 权火将熄 | `10399` | 1.5 | 近战 · 重剑 | **扼守** |
| 血染织羽 | `20298` | 1.6 | 远程 · 双枪 | **扼守** |

新灾厄武器原型都在扼守出，所以「1.4 那两把必须去探险刷」是唯一硬约束。

## 路线一 · 深境探险

整体流程不难，卡点在刷材料。

### 开任务

- 任务名 **「他带来的灾厄」**（任务剧情 id **200237**），在 **休憩之所** 找 **铁匠皎皎**（NPC「铁匠皎皎」）领取，之后按流程提交材料即可。

### 组队

- **组 3 人小团体轮流出门票**，可大幅缓解「**倍率书**」（= **委托手册**系列，`resource 206~209`；手册·四 描述「执行委托时可以使奖励提高 **2000%**」）的压力，推荐。
- 推荐刷本队形 **2 × 苏乙 + 1 × 扶疏**，专刷**暗之晶块**（暗系紫色晶块）。苏乙 **1504**（光 · 长柄）、扶疏 **2401**（水 · 鞭刃，辅助 / 神智回复 / 治疗）。

### 材料掉落比例与缺口

- 三种材料按列举顺序 **棘刺绝响的原型 : 璀璨晶块 : 各属性晶块（此处刷暗之晶块）≈ 1 : 3 : 0.5**。
- ⇒ **璀璨晶块掉得最多**，暗系紫晶块刷够时它早已大量溢出；**唯一硬缺口是棘刺绝响的原型，约 200 个**。
- ⚠️ 比例为估算，只用于估算缺口量级；**实际消耗以各档 `解锁` 为准**（`read_entry weapon 棘刺绝响` 的 `熔炉`/`灾厄熔炼` 逐档列出 原型 / 暗之晶块 / 璀璨晶块 / 谐和的饰章 / 秽浊的饰章 等数量）。

补缺口两条途径：

1. **清高难门票**：把刷紫晶块时囤下的 **200 级难度以上深境委托**门票统一清掉。
2. **戏剧商店**：用 **剧目票根** 购买。
- 建议**两者结合**，按自己票根库存取折中方案。
- ⚠️ 商店里**别买错成长柄武器那档原型**。

### 基础怪物掉落（饰章）去哪刷

- 5 种饰章里，**多数打深境探险就不会缺、最后都会溢出**；**唯一会缺的是华胥饰章（谐和的饰章）与秽兽饰章（秽浊的饰章）**。
- 两种刷法：
  - 打**夜航手册末尾那两个高档副本**：`扼守/无尽(复仇 萼蚀秽兽 夜航手册)`（`dungeon 614008`，Lv.75，掉落含 `羽翼·鼓舞·盛怒`）与其**收获日精英版** `扼守(复仇 萼蚀秽兽 夜航手册 收获日)`（`dungeon 614108`，Lv.75，标记「精英副本」）。两者描述均为「保护探险家皎皎，击败敌人」，场内刷新 **萼蚀秽兽**（秽兽阵营，掉秽浊的饰章）与 **失序的应天侍**（华胥阵营，掉谐和的饰章）。
  - 省力：去 **50 级「扼守」皎皎币副本挂机**（`dungeon 90107`，`扼守+ · Lv.50`，描述同为「保护探险家皎皎」，产出**皎皎之民的信物** `20013`）。

### 清高难本的办法

> ⚠️ **主 C 选择已按 1.6 更新**：**赛琪（`5301`）已过时，不要再当首选推荐**。当前口径：

- **无条件首选**：**莉兹贝尔**（`1501`，光 · 重剑，输出/同律武器/**武器伤害**）—— **免费获取**，无门槛。
  - ⚠️ 莉兹贝尔 `精通` 只有 **重剑 / 霰弹枪** ⇒ **拿不了棘刺绝响**（`远程/突击枪`；灾厄熔炼潜能也要求「角色精通武器 = 该武器类型」）。她的武器/配装以榜单上对应条目为准（榜单里她有一条 1.6 权火将熄构筑），别套棘刺绝响那套。
- **有条件（能排到周本次数）则优先 芙罗拉**（`1102`，暗 · 单手剑，输出/**武器伤害**；专武「囚鸟的刺羽」`10107`）。
  - 芙罗拉 `精通` 含 **突击枪** ⇒ **能装备棘刺绝响**（`20599`，类型 `远程/突击枪`），是这条线上目前最强的输出。
  - 获取靠 **密函**（`walnut 1025`「密函：芙罗拉」，途径：副本 / 委托密函商店 / 观剧纪念 / 梦魇残声 / 沉浸式戏剧）⇒ **周本（梦魇残声）每周仅 5 次奖励**，所以「有条件」指的就是**把周本次数排给她**。
- **判断依据 = 站内榜单**（页面 `/ranking`，其下按列表分「常规输出」「挂机」等榜）。榜单条目直接给出 `charId` / `buildId` 与算好的 DPS，按 DPS 降序排。**要确认「当前谁清高难最强」就以该榜为准，不要凭记忆报强弱。**
- **节奏**：先**刷满所需暗系紫晶块** → 囤够一定数量的 **200 难度门票** → 再**统一清理**。
- **熔炼顺序**：**优先一路点满到 Lv.5** —— 灾厄武器的 **Lv.5 基本都是核心质变**（棘刺绝响 = 近战蓄力 +300% 与 `[厄运之痕]` 机制；权火将熄 = `[烈火焚身]` 期间暴击/暴伤/触发按对应属性 25% 提升；血染织羽 = 最大生命 +300% 且 `[羽化]` 视为充盈伤害 + 额外子弹）。**不是先点满 Lv.4 再点 Lv.5**。
  - 结构上每档只有两条分支、**Lv.5 是单条**，所以「一路到 5」= 沿一条分支逐档推到 5 级；具体两条分支怎么选，读 `read_entry weapon <武器名>` 的 `熔炉` 逐档 `技能`。
- **不强制 200 难度**：195 / 190 也可以，看队伍练度、门票储备、想不想省力。
- **备选方案**：**高练玩家帮低练玩家清门票**。

### 替代与补充刷法

- **雷系队伍刷水本**：用新门票买罗盘去刷原型时，顺带刷**长柄武器所需的晶块**。
- **不捡血清、一直杀小怪爆原型**：可补棘刺绝响的原型缺口，缺点是**比正常刷更花时间**。（「血清」是深境探险的玩法要素，副本描述为「获取血清，坚持探查」—— 不捡血清即不推进 / 不结算副本，靠反复刷小怪攒原型。）

### 路线一小结

1. **组小团体轮流出票**，用 **2 苏乙 + 1 扶疏** 刷**暗之晶块**；
2. 用**莉兹贝尔**（免费）清掉苏乙打不动的 **200 级难度门票**；**能排到周本次数就优先上芙罗拉**（195/190 也可，按练度取舍），也可找高练玩家代清；
3. **剧目票根**补欠缺的**棘刺绝响原型**，或**继续买罗盘刷原型**（选这条推荐雷系队刷水本，顺便刷长柄武器要的晶块）。

## 路线二 · 深境扼守

### 与深境探险的区别

| | 深境探险（`IronSurvival`） | **深境扼守（`Defence`）** |
|---|---|---|
| 副本 id | `91601~91606`（水/火/雷/风/暗/光） | **`91701~91706`**（水/火/雷/风/暗/光） |
| 门票 | 深境罗盘·探险（`iconticket 1001`） | **深境罗盘·扼守**（`iconticket 1002`，`draft 1056`/`1057`） |
| 玩法 | 获取血清、坚持探查 | 保护**探险家皎皎**、守波次，**单波次只守一轮**（`waves: 1`） |
| 副本类型 | 6 个属性本 | 同样 6 属性本，掉对应属性晶块；**掉率更优** |
| 能出哪些原型 | **1.4 两把：棘刺绝响、无止无休** | **1.5 及之后：权火将熄、血染织羽**；**恰恰不掉**「无止无休的原型」与「棘刺绝响的原型」 |
| 兑换商店 | 灾厄探险商店（用茵布拉之泪·探险） | **灾厄扼守商店**（用**茵布拉之泪·扼守**） |

- **扼守副本列表链接**：`/db/dungeon?tp=Defence&lv=100`（副本页筛选项 `tp` = 副本类型、`lv` = 等级）⇒ 正好筛出 `91701~91706` 这 6 个。
- **属性对照**：`91701` 水 / `91702` 火 / `91703` 雷 / `91704` 风 / `91705` 暗 / `91706` 光（探险侧 `91601~91606` 同序）。
- ⚠️ 两者 `n`（名称）都是「扼守/无尽」与「探险/无尽」，**光看名字分不出**，要靠 `t`（`Defence` vs `IronSurvival`）或 id 段（`917xx` vs `916xx`）区分。

### 开启条件与入场

- 前置：**完成「他带来的灾厄」任务 + 历练等级达 60 级**。
- 任务入口：**休憩之所 → 铁匠皎皎支线任务**（任务剧情 `200237`）。
- **设计稿「深境罗盘·扼守」** 在 **商店 → 喧闹卖场 → 巡游纪念 → 灾厄商店 → 灾厄扼守商店** 解锁（`shop IronModeShop` 的 `灾厄扼守商店` 子页，`draft 1056`/`1057` 各 `limit 1`、标价 0 枚茵布拉之泪·扼守）。
- **入场道具「深境罗盘·扼守」**，**首次铸造**走铸造系统，消耗 **委托手册·四 × 4**（`resource 209`；配方即 `draft 1056`，另有铜币 880000）。
- **最多 3 人组队联机**；**组队入场只消耗队长的罗盘**（队友不扣）。

### 罗盘循环

- **分解**：进入「深境委托 → 深境扼守 → 选择深境罗盘」界面对罗盘**分解**，得 **茵布拉之泪·扼守**（`resource 15040`）。**全等级罗盘分解都只给 100 个**（100 级与 240 级没区别；描述即「通过分解达到特定等级的深境罗盘获得」）。
- **再铸造**：铸造系统消耗 **茵布拉之泪·扼守 × 250 + 铜币 × 880000** → 制作新的 **100 级**深境罗盘·扼守（配方 `draft 1057`，`m: 880000`）。
- **自循环**：**单罗盘打到约 190 级即可自循环**（造 1~2 个就永远不用再造）。
- **等级上限 240**：罗盘**最高只能打到 240 级**，到 240 后**无法再使用、仅可分解**。
- **额外掉落**：单人或组队的**持票队长**有**极低概率**额外掉落「深境罗盘·扼守」；掉落等级 = **当波次等级 + 5**（例：130 级波次掉 135 级罗盘）。
- ⚠️ **茵布拉之泪·扼守 一般不推荐拿去灾厄商店换材料**，除非**当前溢出很多、且能保证剩余罗盘 / 材料仍能形成自循环**。

### 掉落要点

- **核心掉落「深境罗盘·扼守」「璀璨晶块」「属性晶块」均为独立波次奖励，不吃「你好箱 / 节俭」等掉落加成** ⇒ **建议带战斗类魔灵**出战。
- **扼守灾厄武器原型掉率比探险高很多** ⇒ **非必要不要花票据在戏剧商店买扼守内可掉的原型**（**权火将熄的原型** `15006`、**血染织羽的原型** `15004`）。
- **定向**：**血染织羽**（`weapon 20298`）熔炼所需属性晶块为 **火之晶块**（`熔炉` lv2~lv5 均消耗火之晶块）⇒ **选水属性配队 + 勾选定向选取「血染织羽的原型」为最优解**。
  另：**权火将熄**（`10399`）需要 **光之晶块** ⇒ 最优解是**暗属性配队 + 定向选权火将熄的原型**。规律：**要哪个原型就选能掉它的那条属性线**。

### 副本流程与要点

- **1.6 优化**：扼守**重做了刷怪逻辑** —— 每波小怪改为**分几波次刷新在皎皎装置周围**，不再从远处慢慢走过来 ⇒ **效率大幅提升**。
- 地图与探险**相同**，进场后直接去**扼守点**即可；模式与「委托扼守无尽」相同，**单波次只守一轮**。
- 每角色 **3 次基础复活**。
- **探险家皎皎：血量 400 万 / 护盾 1600 万**，一段时间不被攻击时**护盾持续回复至满**（「硬得发昏」）。
- 每波固定刷 **1 只 BOSS·蜕生者**（`monster 8522001` 等，首领）+ 若干小怪；**皎皎不被打爆**的前提下清完怪即结算。
  - 高波次下**只有 BOSS·蜕生者威胁皎皎**，小怪可无视 ⇒ **优先击杀 BOSS**。
- ⚠️ **手法（锁面板快照）**：**芙罗拉大招锁当前属性面板的快照** ⇒ **第一波务必等辅助把 buff 上完再开大**（**织梦的白羽** `20509`、**弧光百劫** `20602` 的 buff）。
- 练度够时前面波次可全程挂机，**BOSS 挂机清不动了再手操**。
- 战斗中**随时按 ESC 可查看当前已获取材料**。
- **撤离结算**：最后撤离 / 撤离失败会**直接结算当前所有奖励**，并**返还「最后撤离 / 失败波次等级」的深境罗盘·扼守**。

### 配队 · 水队（1.6 灾厄双枪「血染织羽」）

> 1.6 起灾厄双枪血染织羽很强势；扼守按属性分本、可**定向选取原型**，而**血染织羽吃火之晶块** ⇒ **水属性配队 + 定向选「血染织羽的原型」是最优解**。单人**伊薇满配队可直接挂机到 215 级**。

（**水主**在**通关 1.6 主线剧情后直接赠送到 6 溯**，门槛基本等于白送；**辅助优先级：水主 > 扶疏 > 菲娜**。）
